# 考编模拟卷（冲刺卷）生成

把「一个考试公告 / 一个考试名称」变成 N 套**印刷级、可打印、含最新时政**的笔试模拟卷 PDF（每套 = 试卷 + 答案解析）。

## 一、开工前必须澄清（5 问，缺一不可）

用户给的信息往往不全，**先用 AskUserQuestion 问清 5 件事**，不要猜：

1. **题型结构**：客观题＋主观题？还是纯客观？**有没有图形推理？有没有写作/申论题？有没有多选？**给出贴合该考试往年真题的推荐配比。
2. **输出格式**：统一 PDF / Word / 两者都要。**默认交付 PDF ＋ Word 双版本**（用户 2026-09-17 起固定要求）：PDF 用于印刷，Word 放**独立目录**、按同样的分类子目录存放，命名与 PDF 完全一致（仅扩展名不同）。
3. **命名与目录**：确认"文件夹（公告核心内容）／文件名（年份+考试简称+冲刺卷+序号）"。**默认只建一层，不建学科子目录**（见七）。
4. **卷面版式**：是否需要考情说明、考生须知、密封线、分值构成表、答题区。
5. **素材回避范围**：题目是否可以用本公告的内容命题？（详见三·五，很多考试公告本身是禁区）

## 二、固定调研流程（先考情，后出题）

1. **找公告**：WebSearch「年份+地区+考试全称+人数」，WebFetch 官网原文，提取：报名时间、**笔试时间/时长/满分**、**内容范围**、题型、成绩计算方式、政策依据文号、服务期限、待遇。
2. **找往年考情**：WebSearch「地区+岗位+笔试+真题+题型+分值」。同类卷的题型配比高度可迁移：
   - 广东社区/基层岗位常见配比：单选30—40题 + 多选10—15题 + 判断10—20题 + 简答/案例分析/公文写作（合计40—50分），时长 90 分钟、满分 100 分。
3. **抓最新时政**（关键，见第四节）。
4. **抓政策原文**：WebFetch 省人社厅"高校毕业生就业创业扶持政策清单"等原文，**逐条记录金额/期限/比例**（这是就业创业政策题的唯一可靠来源）。

## 二·五、配比核实：出题前必须先锁死模块配比（血泪，最贵的错）

**教训**：曾按"常识20/言语25/判断推理35/数量10/资料10"出了整整 5 套卷、还交付了，后来才发现广东选调官方配比是 **15/15/15/40/15**——判断推理多了不存在的"定义判断"、数量关系少了广东特色的"数字推理"、资料分析只有 2 组材料。**整卷推倒重建。**

**规矩**：动笔写题之前，先花 10 分钟做配比核实，**至少 3 个来源交叉**（培训机构题型分值文章、往年考生回忆版、招考公告/考试大纲），口径一致才落笔。搜索模板：`{年份}年度 {考试全称} 各类题型分值`、`{考试} 行测 题型 题量 分值`。

## 三·五、命题素材的"回避红线"（用户会明确交代，务必先问）

有些考试的公告本身**不能拿来命题**——肇庆基层就业创业服务岗就是：用户明确要求"**不要用公告的内容做题目**"，即招录人数、报名时间、待遇标准、招募程序等一律回避。

- **开工前先问一句**："题目素材是否可以取自本公告？"
- 若不可用，政策类题一律改走**该省公开的扶持政策清单**（广东：一次性创业补贴 1 万元、一次性求职补贴 3000 元、一次性扩岗补助 ≤1500 元、灵活就业社保补贴 300 元/月×最长 3 年、就业见习补贴 ≤12 个月、创业担保贷款个人 30 万／小微企业 500 万、创业租金补贴珠三角 6000 元·其他 4000 元）。
- 这类政策数字**必须联网核到原文**再写，金额和期限是高频干扰项。

## 三·六、跨套去重与难度分级（用户 2026-09-23 反馈"三套重复率高、难度偏简单"后固化）

### 3.1 难度必须用字段量化，不能凭手感

**事故**：三套卷被评价"重复率高、难度偏简单，实际考试难度更高"。根因有二：① 三套卷共用同一批"最典型"的考点，命出来自然雷同；② 出题时凭手感选题，容易偏向表述直白、一眼能答的题。

**做法**：题库每条题必须带 `level` 字段（`'易'` / `'中'` / `'难'`），并写死配额。

```python
# BANK_SPEC.md 里的字段表要加这一行
# | `level` | 难度自评：'易' / '中' / '难' |
# | `src`   | 出处。时政/省情题必填 |

LEVEL_TARGET = {'难': 0.30, '中': 0.50, '易': 0.20}    # 三套合并统计
LEVEL_TOL    = 0.06                                     # 各档允许 ±6 个百分点

def audit_level(QS_all):
    cnt = collections.Counter(q['level'] for q in QS_all)
    n = sum(cnt.values())
    for lv, tgt in LEVEL_TARGET.items():
        got = cnt[lv] / n
        assert abs(got - tgt) <= LEVEL_TOL, f'难度档 {lv} 占比 {got:.1%}，目标 {tgt:.0%}'
```

实测参考（普宁 3 套 × 50 题）：`{'中': 0.48, '难': 0.307, '易': 0.213}`。

**"难"从哪来——题干情境化，而不是把选项写偏。** 难度靠**设问层次**拉开，不靠冷僻知识点：

- **题干字数下限**（写进自检）：单选 ≥ 30 字；**法律、公文类 ≥ 40 字**。
- **法律题**：给一个具体工作情境（"某事业单位编外聘用人员小郑因个人原因提出辞职…"），问"这一做法是否符合规定"，而不是直接问法条内容。
- **公文题**：给一份具体行文场景（"某县卫生健康局因突发公共卫生事件情况紧急，直接向省卫生健康委请示，同时抄送了市卫生健康委"），问是否符合行文规则。
- **时政题**：不要只问"某事件发生在哪"，而是问"该条例规定面向服现役满一定年限的高校毕业生退役军人招考，这一年限是"，把数字考在情境里。
- **省情题**：用本地真实数据做干扰项（"2025 年纺织服装产值 1413 亿元"），而非泛泛的"下列说法正确"。

### 3.2 跨套去重：两道卡口

**卡口一：题干 3-gram Jaccard 相似度 < 0.60。**

```python
def _fp(s):
    s = re.sub(r'[^\u4e00-\u9fa5A-Za-z0-9]', '', s)
    return {s[i:i+3] for i in range(len(s) - 2)}      # 3-gram 集合

def _jac(a, b):
    A, B = _fp(a), _fp(b)
    return len(A & B) / len(A | B) if (A | B) else 0.0

# 跨套断言：任意两套之间，任意两题的题干相似度都必须 < 0.60
for i in range(1, SETS + 1):
    for j in range(i + 1, SETS + 1):
        for a in sets[i][0]:
            for b in sets[j][0]:
                assert _jac(a['stem'], b['stem']) < 0.60, (i, j, a['no'], b['no'])
```

⚠️ **相似度卡口只能防"题干撞车"，防不住"考点撞车"**——同一道题换个说法就能绕过。所以必须有第二道。

**卡口二：考点全局唯一（`point` 字段）。**

```python
def _zkey(z):        # 主观题的考点键要细分
    if z['kind'] == '公文写作':
        return f"公文写作·{_wen_zhong(z['stem'])}"   # 通知/请示/通报/报告/函 分开算
    return f"{z['sect']}·{z['module']}"

seen = {}
for si, (QS, ZS) in sets.items():
    for q in list(QS) + list(ZS):
        k = _zkey(q) if 'kind' in q and q.get('kind') in ('简答','案例分析','公文写作') \
            else f"{q['sect']}·{q['module']}·{q.get('point','')}"
        assert k not in seen, f'考点重复：{k}（第{seen.get(k)}套 与 第{si}套）'
        seen[k] = si
```

**踩过的两个坑**：
1. **主观题按 `sect·module` 当键太粗**——三套都考公文写作，键都是"公文写作·公文写作与处理"，必报重复。必须按**文种**细分（通知/请示/通报）。
2. **判断题与单选题会撞同一考点**——判断题先写了"上合峰会举办地"，单选也考同一件事。判断题的考点最容易和单选重叠，**起草时就要让子代理在 `BANK_SPEC.md` 里声明"我已避让哪些考点"**，主代理汇总后再查一遍。

**卡口三（2026-09-23 新增，最重要的一条）：事实级查重——`point` 是自由文本，靠不住。**

**事故**：`point` 由子代理手写，同一件事换个措辞就能绕过卡口二。普宁卷交付前用专有名词扫了一遍，查出三处硬重复：

| 重复事实 | 第 1 处 | 第 2 处 | 为什么卡口二没拦住 |
|---|---|---|---|
| 七一勋章 | 多选「时政·重要表彰·**七一勋章获授人员**」 | 单选「时政·重要表彰·**七一勋章**」 | 两个 `point` 字符串不同 |
| 2026 年 GDP 预期目标 | 单选「时政·全国两会·**2026年经济预期目标**」 | 判断「时政·全国两会·**预期目标表述辨正**」 | 同上 |
| 神舟二十一号在轨时长 | 科技单选（选项含「210 天」） | 时政判断（「180 天」为错误项） | 跨模块，数字还不同（210 vs 180），**连相似度都极低** |

第三条最险：两题的正确答案都是「210 天」，但一题写 210、一题写 180 做干扰，`point`、题干、数字**全都不一样**，只有人工读才能发现。

**做法：独立于 `point`，按题干里的专有名词再查一遍，并用白名单管理"可接受的跨模块重合"。**

```python
PROPER = re.compile(
    r'《([^》]{2,40})》'                                  # 书名号：法规/文件/文章
    r'|(生态环境法典|七一勋章|政府工作报告|长期护理保险|平陆运河|全国生态日'
    r'|世界人工智能|长征胜利|神舟[一二三四五六七八九十\d]+号|习近平文化文选'
    r'|长三角|夏粮|海洋生产总值|服务进出口|自然保护区|西部铁路|老龄人口'
    r'|二十届五中全会|中央纪委|世界技能大赛|载人航天|国家最高科学技术奖)')

# 允许跨套重合的专有名词 —— 每条必须写明理由，理由只能是「跨模块、考不同角度」
ALLOW_CROSS = {
    '政府工作报告': '第1套在省情模块考广东省报告的 2025 年数据，'
                    '第2套在时政模块考全国两会的 2026 年预期目标，层级与考点均不同',
    '生态环境法典': '第1套在法律模块考法典确立的基本制度，'
                    '第3套在时政模块考配套司法解释的施行日期，角度不同',
}

def audit_facts(sets):
    facts = collections.defaultdict(set)
    for si, (QS, _) in sets.items():
        for q in QS:
            for m in PROPER.finditer(q['stem']):
                facts[m.group(1) or m.group(2)].add(si)
    cross = {k: sorted(v) for k, v in facts.items() if len(v) >= 2}
    # 白名单按子串匹配：《中华人民共和国生态环境法典》要能命中「生态环境法典」
    bad = [k for k in cross if not any(w in k or k in w for w in ALLOW_CROSS)]
    assert not bad, f'专有名词跨套重复且未列入白名单：{[(k, cross[k]) for k in bad]}'
```

**白名单纪律**：`ALLOW_CROSS` 里每一条都要写清"哪套考什么模块的什么角度"。**写不出理由的，就不是可接受的重合，必须换题。** 白名单本身要按考试的素材特点逐次重写（下一个考试的专有名词完全不同），别照抄。

**这三道题的替换方案**（可作参考）：
- 七一勋章 → 换成「政协十四届全国委员会常务委员会第十八次会议协商议政主题」
- GDP 预期目标 → 换成「西部铁路营业里程五年间变化」
- 神舟二十一号在轨时长 → 把科技模块那道改成**纯通识题**（载人飞船 vs 货运飞船的分工），不再引用具体数字

### 3.3 子代理并行起草时的分工要求

多模块题库并行起草（8—9 个 agent）时，在 `BANK_SPEC.md` 里写死三条，否则合并时必炸：

1. **每个子代理声明"本模块考点清单"**，主代理汇总成全局表后回传，让子代理自查避让。
2. **每个子代理的题量要留冗余**（目标题量 × 1.3），因为合并时会有考点撞车要删。
3. **主观题（简答/案例分析/公文写作）由主代理自己写**——子代理容易把公文范文写成"提纲式"，缺主送机关、落款、日期，返工成本高于自写。

实测有效：普宁卷的 `bank_fl` 子代理自己发现"生态环境法典施行日期""退役军人条例施行日期"已被 `bank_sz` 覆盖，主动删掉两道单选换成民法典·人格权、劳动合同法·竞业限制。**给子代理一份考点表，它会自己避让**。

## 四、时政时效规则（硬要求）

- 时政题必须覆盖到**公告发布当月**（即"当下最新月份"）。
- 搜索模板：`{年份}年{M}月 时政热点 重大事件 政策 汇总`、`{年份}年{M}月 国内时政 习近平 重要讲话`，配合 freshness 参数取近 2—3 个月。

### 四·一、时效硬约束：白名单制 + 年份断言（用户 2026-09-23 反馈"大量 2024 年的时政"后固化）

**事故**：多套卷里混进大量 **2024 年**的时政事件。学员一眼看出卷子陈旧，直接质疑"是不是几年前的题"。根因是出题时靠记忆补题，而模型的记忆里 2024 年的"重大事件"最密集、最好写。

**机制（两道，缺一不可）**：

**① 白名单制——先把素材固化成清单，再据清单出题。**

出题前先写一份 `shizheng.md`（放在 `_build/<简称>/` 下），格式：

```markdown
# 时政素材清单（更新至 YYYY 年 M 月）

> 每套卷至少 4 题取自公告发布前 3 个月内；不得出现 YYYY-1 年及更早的事件。

## 一、重要会议与决策
- **二十届五中全会**（2026-10 在北京召开）· 出处：新华社 2026-08-…
## 二、法律法规与新规
- **《中华人民共和国生态环境法典》**（2026-08-15 施行，我国第二部以"法典"命名的法律）· 出处：…
```

每条**必须带日期与出处**。清单写完之后，题库文件只准从清单里取料。

**② 年份黑名单断言——机器兜底。**

在 `assemble.py` 的跨套校验里加：

```python
BAN_YEARS = ('2024年', '2023年', '2022年', '2021年', '2020年')   # 按公告年份往前推
```

### 两个进阶发牌器（多模块卷必备）

**① `alloc_stratified()`：按子类分层发牌**。普通 `alloc()` 只保证总数与答案均衡，**不保证子类比例在套间一致**——题库里公文题多、省情题少时，第 3 套可能一道省情都没有。做法是逐子类单独发牌再合并：

```python
def alloc_stratified(pool, groups, seed_base):
    """groups = [(sub, [第1套题量, 第2套题量, …]), …]"""
    n = SETS; out = [[] for _ in range(n)]
    for i, (sub, per) in enumerate(groups):
        assert len(per) == n, (sub, per)
        subpool = [it for it in pool if it['sub'] == sub]
        assert len(subpool) >= sum(per), (sub, len(subpool), sum(per))
        got = alloc(subpool, list(per), seed=seed_base + i)
        for j in range(n): out[j].extend(got[j])
    return out
```

⚠️ **每套题量必须写成列表而不是单一数字**：`('省情市情', [2,2,1])`。写死成「每套 2 题」时，只要池子只有 5 题、而 3 套 × 2 = 6，就会断言失败 `('省情市情', 5, 6)`——真题库各子类存量常常不是套数的整数倍，先统计再配比。

**② `alloc_prior()`：保障某个特征的题目在每套都出现够量**。时政题最容易出问题：纯按答案均衡发牌，可能三套里有两套只抽到 1—2 道「公告发布当月」的题。做法是**枚举种子直到满足下限**：

```python
SEP_MARKS = ('9月', '9 月')          # 公告发布当月，注意全角/半角两种写法都要匹配
def _n_sep(items):
    return sum(1 for it in items if any(k in it['stem'] + it['parse'] for k in SEP_MARKS))

def alloc_prior(pool, needs, seed_base, min_sep, tries=800):
    for off in range(tries):
        out = alloc(pool, needs, seed=seed_base + off)
        if all(_n_sep(o) >= min_sep for o in out):
            return out
    return alloc(pool, needs, seed=seed_base)     # 兜底：退化为普通发牌
```

时政单选设 `min_sep=3`、时政多选 `min_sep=1`（实测三套分别 4/6/5 题，断言写进 `verify_all.py`）。

## 六·五、答案解析册的"字母错位"陷阱（高频致命错误）

批量生成解析时，最容易出现两类事故，**必须在交付前用脚本卡住**：

1. **解析首句/末句的选项字母被模板写死**。典型症状：全册每题都写"A项正确""故选A"，与速查表标答完全脱节；或"题干选项内容对得上、但字母对不上"（如正确答案是D，解析却描述D项内容却标成"C项正确"）。
2. **图形推理题的图与解析不是同一道题**。生成时图形被简化/错位，解析却按原设计写（例如解析写"三行图形、去同存异"，卷面实际只印了单行三格）。

**做法（已验证）**：
- 用 Python 脚本持有 `(题号, 答案, 考点, 解析)` 四元组数据，**答案速查表由同一份数据反推生成**，从结构上消灭不一致。
- 交付前跑断言：
  ```python
  for n, a, k, e in ALL:
      assert e.rstrip().endswith("故选%s。" % a), (n, a)   # 解析末句字母 = 标答
  assert [x[0] for x in ALL] == list(range(1, 101))       # 题号连续无缺
  ```
  再对成稿 PDF 复核：`flat.count('考点：') == 100`、`flat.count('故选') == 100`。
- **图形推理题必须回到卷面图形核验**，不能信解析：
  ```python
  import pymupdf, numpy as np
  d = pymupdf.open(paper_pdf)
  # ①矢量法：拿线条/方块的精确坐标（注意 pymupdf 返回的坐标可能与渲染坐标存在整体缩放，
  #   但同一图形内部的相对关系可信）
  for dr in d[10].get_drawings():
      if 50 < dr['rect'].y0 < 125: print(dr['rect'])
  # ②像素法：在渲染图上按行/列统计暗像素游程，定位每个元素的位置
  pix = d[10].get_pixmap(dpi=600, colorspace=pymupdf.csGRAY)
  img = np.frombuffer(pix.samples, dtype=np.uint8).reshape(pix.height, pix.width)
  ```
  图形题常见规律只有五类，逐个套：**数量（个数/边数/线段数/竖线总长）→ 位置（旋转/平移/换行/遍历）→ 样式（去同存异/黑白叠加/填充交替）→ 属性（对称/曲直）→ 对称轴条数**。若标答套不进任何一类，多半是标答错了，**要敢于更正并在该题解析中写清理由**。
- **逐格提取矢量参数，不要只看缩略图**。把 `dr['items']` 里的线段换算成「角度＋长度」再按格子分组，规律一眼可见：
  ```python
  for dr in pg.get_drawings():
      segs = []
      for it in dr['items']:
          if it[0] == 'l':
              a, b = it[1], it[2]
              ang = math.degrees(math.atan2(b.y - a.y, b.x - a.x)) % 180
              segs.append((round(ang, 1), round(math.hypot(b.x - a.x, b.y - a.y), 1)))
          elif it[0] == 're': segs.append(('re', round(dr['rect'].width, 1), round(dr['rect'].height, 1)))
          elif it[0] == 'c': segs.append(('c',))          # 曲线（圆/弧）按 4 段 CURVE 计 1 个图形
  ```
  经验：**一个圆＝4 个 `c`**；同一条竖线若同时出现「全长」和「半长且 x 相同」两个 rect，说明生成器把"短竖线"错画在长竖线同一 x 上（印出来只是半段加粗），属图形缺陷，别当成"两条线"。
- **判定"两格图形是否完全一样"用像素差分**，不要靠肉眼：
  ```python
  def grab(pg, x0, x1, y0, y1):
      pix = pg.get_pixmap(dpi=300, clip=pymupdf.Rect(x0, y0, x1, y1))
      return np.frombuffer(pix.samples, dtype=np.uint8).reshape(pix.height, pix.width, pix.n)[:, :, 0]
  print(np.abs(grab(pg, 241.6, 297.6, 167.2, 223.2).astype(int) - grab(pg, 297.6, 353.6, 167.2, 223.2).astype(int)).mean())
  ```
  `mean < 3` 即两格基本相同——这往往意味着**该题图形印错了**（题干出现两个一模一样的格）。此时的处理：**保留原标答**（按最可能的命题意图给出规律解释），并在该题解析中写明"某两格印制差异不明显／图形存在缺陷"，**不要擅自改标答**。
- **对称轴条数也是常见规律**：等腰三角形（非等边）1 条 → 一条线段 2 条（所在直线＋中垂线）→ 等边三角形 3 条 → 正方形 4 条 → 正五边形 5 条。遇到「图形种类跳来跳去、数量又对不上」的题，先数对称轴。

## 六·六、页脚与页码

无头 Edge 的 `--no-pdf-header-footer` 会去掉页码，Chromium 又不支持 `@page` 的 `@bottom-center { content: counter(page) }`。**用 pymupdf 二次盖章**（内置 CJK 字体 `china-ss` 可直接排中文）。

```python
import re
import pymupdf

_SEG = re.compile(r'[\x20-\x7E]+|[^\x20-\x7E]+')      # ASCII 可打印段 / 非 ASCII 段

def _font(seg):
    return 'helv' if seg.isascii() else 'china-ss'

def text_width(text, size=7.6):
    return sum(pymupdf.get_text_length(m.group(0), fontname=_font(m.group(0)), fontsize=size)
               for m in _SEG.finditer(text))

    for m in _SEG.finditer(text):
        seg = m.group(0)
        page.insert_text((x, y), seg, fontname=_font(seg), fontsize=size, color=color)
        x += pymupdf.get_text_length(seg, fontname=_font(seg), fontsize=size)

doc = pymupdf.open(src); n = len(doc)
for i, page in enumerate(doc):
    y = page.rect.height - 26
    page.draw_line(pymupdf.Point(39.7, y - 11), pymupdf.Point(page.rect.width - 39.7, y - 11),
                   color=(0.80, 0.84, 0.88), width=0.6)
    draw_mixed(page, 39.7, y, LEFT)
    txt = "第 %d 页 / 共 %d 页" % (i + 1, n)
    draw_mixed(page, page.rect.width - 39.7 - text_width(txt), y, txt)
doc.save(dst, garbage=4, deflate=True)
```

## 六·八、表格横向溢出：静默裁切 + Edge 缩放伪装（最阴险的坑）

A4 纵向（595pt）去掉 `margin:15mm 14mm` 后**可用版心宽约 507pt**。表格一旦超出：

1. **末尾列被直接裁掉，且没有任何报错**。实例：答案速查表 10 题/行 = 20 个 `td`，`min-width:32pt + padding:7pt` 需约 620pt → 每行最后 2 题消失，100 条只剩 82 条，肉眼扫一眼根本发现不了。
2. **Edge 会整体缩放页面来"适应"溢出内容**，导致页数虚低、字号变小。所以修好溢出后页数**变多**是正常的（曾出现答案册 9 页 → 16 页），别误判成出错。

**做法**：
- 答案速查表要 10 题/行，单元格必须 `padding:2pt 4.5pt; min-width:11pt`（约 44pt/题 → 10 题 440pt < 507pt）。
- **多选答案（`ABCD` 四字符）必须单独排 5 题/行**：10 题/行时每行 20 个 `td`，每个仅约 25pt，扣掉左右 padding（4.5pt×2）后内容宽只剩约 16pt，而 `ABCD` 在 9.2pt 字号下需约 23pt → 会被 `overflow:hidden` 静默裁掉末尾字母（速查表看上去「有 ABCD」，其实印出来是 `ABC`）。组卷时按题型分别设 `per`：单选/判断用 10，**多选用 5**。判断题答案是 `√/×` 单字符，10 题/行无问题。
- 交付前必跑越界扫描（文字 + 图元都要扫）：
  ```python
  W = doc[0].rect.width
  for i, p in enumerate(doc):

  ```
- **必加 PDF 层断言**（HTML 层全对不代表 PDF 对）：

## 六·九、答案分布必须拉平（易被忽略的硬伤）

批量出卷时标答会严重偏斜（实测某套 A 占 53 个、D 只有 9 个），学员一做就看出来。**目标：ABCD 各 24—26 个，且各模块内部也要均衡。**

不要改题干，用**选项对换 + 同步改写解析字母指代**的机械置换：

```python
TOK = re.compile(r'(?<![A-Za-z])[ABCD](?![A-Za-z])')          # 排除 GDP / AI / 5G
LIST_XIANG = re.compile(r'[ABCD](?:\s*[、,，和及与]\s*[ABCD])*\s*项')  # "B、C、D 项"
def safe_at(s, i, j):                                          # 只认安全语境
    if LIST_XIANG.match(s, i): return True
    if s[i-1:i] in '（(': return True
    return s[max(0,i-4):i].rstrip().endswith(('选项','第','选'))
```

- 解析里**只要有一个字母处于歧义语境（A股 / B超 / B市）就整题跳过**，宁可不均衡也不误改。
- 置换后把 `B、C、A 项均错` 这类并列串按 ABCD 重排，否则读起来别扭。
- **图形推理题不参与置换**：选项画在 SVG 里，换字母会图与标答对不上。用题号集合排除。
- 置换后重跑 `故选X` 断言，确保末句与新标答一致。
- **并列字母串置换后必须按 ABCD 重排**，否则会印出「A、C、B三项」：
  ```python
  SEQ = re.compile(r'[ABCD](?:、[ABCD])+')
  def _sort_lists(s):
      return SEQ.sub(lambda m: '、'.join(sorted(m.group(0).split('、'))), s)
  ```
- **数值升序判定必须支持中文数词与单位换算**：只认 `[\d.]+` 会把「5000元／8000元／1万元／2万元」这种同族升序选项置换乱。做法：`_cn2int` 解析中文数词（一~十、十X、X十Y），`_FAM` 按单位分族（元/万元/亿元、个月/年、%/倍/人/名/公里…），**族不同视为不可比**，同族且升序才冻结。
- **PDF 层数「故选」要先压平空白**：换行会把 `故选 C。` 的标记切断，直接 `count` 只数到 44/50 会误判。正确写法 `flat = re.sub(r'\s+', '', t_a)` 后再 `flat.count('故选') == 单选数`。判断题解析末句固定「选 √。」/「选 ×。」，另设一套断言。
- **多套卷的分布不要"逐套手调"，用「材料分套 × 发牌种子」联合穷举一次搜出全局最优**（本次汕头 3 套 × 100 题实测：跨套同字母极差 2、套内极差 ≤ 2，三套分别为 `{A24,B26,C26,D24}` / `{A25,B25,C26,D24}` / `{A24,B26,C26,D24}`）：
  ```python
  # ① 资料分析材料分套：枚举 C(9,3)×C(6,3)/3!，取偏差最小
  # ② 发牌种子：0—299 枚举
  # 目标函数 = 10×跨套同字母极差 + Σ(各套内 A/B/C/D 极差)
  ZL_SPLIT    = [(3, 4, 2), (6, 1, 8), (0, 7, 5)]   # 勿手改
  SEED_OFFSET = 42                                   # 勿手改
  ```
  结果写死成常量并标「勿手改」；**改了配比或题库就必须重跑 `assemble.py --search`**，否则常量与题库脱钩、均衡会悄悄退化。
- **图形题的答案位置单独硬控**：图形题不参与均衡器（选项在 SVG 里），用一张 `PLACE` 表指定每题标答落在哪个字母位，把标答图形搬到该位，再用 `balance._remap()` 同步改写解析里的字母指代。这样图形题也能计入 A/B/C/D 配额（本次 15 题拉到 A4 B4 C4 D3）。
- **红线词要防误伤**：类比推理的合法选项内容可能就是「教师∶粉笔」，所以红线词表写「**粉笔教育**」而不是「粉笔」；写「中公教育」而不是「中公」（页脚要留「广东中公教研」）。
- **多选还要管"正确项个数"的分布**：均衡器只管字母、不管个数，容易连着出「ABCD 全选」。出厂加断言：三套合并统计，**正确项 2 / 3 / 4 个的题都要有**（例如 15 题里 2 项约 5—6、3 项约 5—6、4 项约 3—4），并限制「全选」总数。均衡键用完整答案串 `it['ans']` 时这条要单独查。

### 六·九·补、多选题的字母双射重排（2026-09-23 新增，解决"A 占比过高"）

**事故**：某套 30 道单选里 **A 占 12 道**。根因两个，都很隐蔽：

1. **均衡器把多选与单选混在一组算目标**。单选靠"字母对换"能调平，但多选的答案是 `ABC`/`ABCD` 这种**字符串**，单字母对换改不动它，于是均衡器在多选题上白费力气、把单选的份额也带偏了。
2. **统计口径把判断题算进了字母分布**。判断题选项固定为「正确/错误」= A/B，天然拉高 A、B 的计数。

**修复二：`rebalance_multi()` 用字母双射整体重排。**

```python
def _bijection(S, T):
    """构造字母双射，使 S 映射为 T（S、T 均为升序字母串）。"""
    return dict(zip(S, T))

def _swap_multi(q, target):
    """把多选答案串整体重排到 target：选项、答案、解析末句一起改。"""
    m = _bijection(q['ans'], target)
    tmp = {}
    for k, v in q['opts'].items():
        tmp[m.get(k, k)] = v
    q['opts'] = {k: tmp[k] for k in 'ABCD' if k in tmp}   # 键顺序卡死，见八
    q['ans'] = target
    # ⚠️ 解析末句「故选XXX。」必须单独摘出改写——
    #    多选答案是 ABC 连写，会被 (?<![A-Za-z])[ABCD](?![A-Za-z]) 这种词边界断言整串跳过
    mm = TAIL.search(q['parse'])
    if mm:
        head = q['parse'][:mm.start()]
        tail = '故选%s。' % ''.join(sorted(m.get(c, c) for c in mm.group(1)))
        q['parse'] = head + tail
```


## 六·十、矢量图形推理题的画法（不要截图、不要位图）

要求"用矢量工具精确绘制"时，**手写 SVG** 是唯一可控解（PDF 内 0 位图，放大不糊）：

- `figlib.py` 图元库：`rect / circ / line / poly / path / arrow / nstar / ngon / tri_up / diamond / wave / arrow_dir(cx,cy,deg)`，统一 `_s(body)` 包裹。
- `genfigs.py` 题库：每道题一个 dict（题干 SVG + 选项 SVG + 标答 + 规律说明），按 `fig{N}_{M}.svg` 落盘。
- **SVG 尺寸是头号坑**：外层 `<svg>` 必须 `style="display:block;max-width:100%;height:auto;margin:0 auto"`。写成 `width="100%" height="100%"` 会让每个单元格都撑满整页，行测从 12 页膨胀到 23 页。
- CSS 里再兜一层：`.figblk > svg.figgrid{width:300px!important;height:300px!important}`、`.figseq,.figopt{max-width:380px!important}`。
- 图形题在数据结构里 `opts={}`（选项画在 SVG 内），但 **`ans` 必须给值**，否则答案速查表 KeyError。
- **图形题的选项会因生成器参数越界而"静默重复"——卷面看不出来（最险的一处）**：本次「元素种类数」题里 `cell(6)` 取 `order[:6]`／排布表 `[:6]` 双双越界，而图元字典只定义了 5 种元素 → 选项 B、C 图形**完全相同**。三道防线一起上：
  1. 图元种类数必须 ≥ 该题最大元素数（本次补第 6 种：七边形 `ngon(cx,cy,r,7)`）；
  2. 逐元素数定制排布表（`{1:([(50,50)],22), 2:([(30,50),(70,50)],18), …}`），别用 `POS[:n]` 切片；
  3. 出厂总检加**结构性断言**：四个选项单元格两两不同。
     ```python
     cells = re.findall(r'<g transform="translate\(0,24\)">(.*?)</g></g>', f['opts'], re.S)
     assert len(cells) == 4 and len(set(cells)) == 4
     ```
  ⚠️ **题干图形则允许重复**（周期为 3 的轮换规律，第 1、4 图本就相同），断言只能放宽为 `len(set(stem_cells)) >= 3`，写成 `== n` 会误报。
- **图元生成器的 `order[:n]` 与 `POS[:n]` 必须同长**：这两处长度不一致时不会抛异常，只会静默少画／重画，务必用上面的集合断言兜底。
- **`check_figs.py` 的几何指纹必须把 `<path d="...">` 算进去**：波浪线、曲线、折线都是用 `<path>` 画的，只认 `polygon/rect/circle/line` 的指纹会把它们全当"没有图元"，误报「题干图形种类过少」（本次 5 道题一起误报）。做法：`_prims()` 同时抽出 `('path', d, filled)`，把 `len(paths)` 与排序后的 path 串并入指纹；坐标归一化时 path 的数字序列要按 `nums[0::2]`=x、`nums[1::2]`=y 取（其余图元取法不同，别混用）。
- **出厂必须断言"全矢量、零位图"**：`verify_all.py` 里对每份 PDF 断言 `sum(len(p.get_images()) for p in doc) == 0`，同时统计 `get_drawings()` 的矢量图元数（本次每套 9800+）作为"图确实画进去了"的正向证据。有人图省事把 SVG 转成 PNG 贴回去时，这条会立刻拦下。

## 六·十一、资料分析：没有材料的"资料分析"是废题（用户会当场退回）

**典型翻车**：10 道题全是"根据材料，……"的裸题干，卷面上根本没有材料；卷首还印着"含 2 组材料"；甚至混进"如果…则…"的数量关系应用题。实测被用户直接打回，评价"太粗糙、题干不完整"。

**真题形态（必须照做）**：**题量按考试定，组数 = 题量 ÷ 5**。广东选调资料分析 15 题 → **3 组材料 × 每组 5 题**（曾误用 2 组被退回）。每组材料 = **标题 ＋ 文字说明 ＋ 统计表或统计图 ＋ 注释**。

- **题型要齐**：求比重、求增速、求增长量、求倍数、两期比较、综合分析（"下列说法正确的是/不正确的是"）。一组 5 题里最好覆盖 4—5 种。
- **材料形式要有变化**：统计表、柱状图、折线图轮换；一组材料里也可以"图＋表"并用。
- 图表**手写 SVG**（别截图、别用位图）：坐标轴＋虚线网格＋刻度＋数值标注，配色沿用卷面藏青 `#12395C` / `#4A7EAF`。
  - 折线图若显式指定 ymin/ymax，**不要再叠加自动边距**，否则刻度会变成 57.98 / 60.02 这种难看的数。
- 材料数据必须**内部自洽**：分项之和＝总计、表内增速与两期数值对得上。
- 答案册要**复现材料**（可压缩版），学生才能对着解析看。

**数据模型**：把材料挂在该组首题上，渲染时"遇首题先出材料"。

```python
dict(module='资料分析', stem=..., opts={...}, ans='B', point='资料·比重计算',
     parse='…故选 B。', mat=MAT, chk={'A': (expr, 'eq', 56.8, 0.06), ...})
```

**最关键的校验——数值自证**：给每题每个选项写一个表达式，用材料数据重算，断言"**恰好一个选项成立，且它就是标答**"：

```python
SAFE = {'min': min, 'max': max, 'round': round, 'abs': abs}
def _eval(expr, data):
    ns = dict(math=math); ns.update(data)
    return eval(expr, {'__builtins__': SAFE}, ns)

for L in 'ABCD':
    expr, op, thr = chk[L][:3]; tol = chk[L][3] if len(chk[L]) > 3 else 0.005
    ok = abs(_eval(expr, D) - thr) <= tol if op == 'eq' else OPS[op](_eval(expr, D), thr)
    if ok: hit.append(L)
inv = ('不正确' in stem) or ('错误的是' in stem)      # 三真一假
assert len(hit) == (3 if inv else 1)
assert (set('ABCD') - set(hit)).pop() == ans if inv else hit[0] == ans
```

表达式写法：求值题用 `'adv25/ind25*100'` 配 `eq`；比较题用 `'rev_g-ind_g'` 配 `gt 0`；复合判断用 `'min(a,b)'` 把多个条件揉进一个表达式。

**注意**：`eval` 默认拿不到 `min/round`，必须显式放行白名单内置函数，否则报 `name 'min' is not defined`。

数值选项**保持升序**，所以资料分析要**排除在答案均衡器之外**（把题号并入 frozen 集合），否则会被换成非升序。

## 六·十二、分页控制：只有 `break-inside: avoid` 生效（肇庆卷最贵的发现）

**`page-break-inside: avoid` 在 Chromium/Edge 里不生效**。只写这条旧语法时，`.q`（题干＋选项，或题干＋图形块）会被**从中间劈开跨页**：本次第 41 题题干留在第 6 页末、九宫格图形被挤到第 7 页。

定稿写法（两个都写，旧引擎兜底）：

```css
.q { break-inside: avoid; page-break-inside: avoid; }
.opts { break-before: avoid; break-inside: avoid; }
.stem { break-inside: avoid; }
```

- **绝不要给 `.q` 加 `break-after: avoid`**：会串成长链，把每道题都顶到次页，页数暴涨。
- `display: inline-block; width: 100%` 虽然也能锁页，但会把**第 1 题无理由挤到第 2 页**，弃用。
- **排查手法：改一个属性渲一版，做变体对照**。本次做了 4 变体（A 原样 / B 去 `sec-title` 的 `break-after` / C 去 `.sub-sec` / D 去 `display:inline-block`），用**总页数 + 目标题落在第几页**两个指标判定，别凭感觉改。
- 页数突然变化时，先查横向溢出（见六·八，Edge 会整体缩放伪装），再查分页属性。

### 末页「寡妇页」：卷末加结束语 + 草稿区

固定题量的卷子，末页常常只剩 1—2 题，填充率掉到 **8%—17%**，看着像没做完。**做法**：卷末追加一个 `.closing` 块 = 结束语 + 草稿区（客观卷的数量关系、资料分析确实需要演算空间，不是凑数）。

```html
<div class="closing">
  <div class="cend">—— 试 卷 到 此 结 束 ——</div>
  <div class="cnote">以下空白处可作为草稿区使用，请勿在此区域书写与作答无关的内容。</div>
  <div class="draft"><div class="dline"></div> × N</div>
</div>
```
```css
.closing { break-inside: avoid; page-break-inside: avoid; }
.dline   { border-bottom: 0.7px dotted #b9c4d0; height: 1.62em; }   /* 每行 ≈16.5pt */
```

**行数 N 要卡到「放得回末页」**，这是关键：
- 块高 ≈ 44pt（标题+说明）+ N × 行高（`.dline{height:1.62em}` ≈16.5pt；收到 `1.32em` ≈13.5pt）。
- N=30（≈539pt）会**差十几 pt 放不下**，整块跳到新页，反而把前一页留白到 24.8%（比不加更糟）。
- **N=27（≈490pt）刚好**（行高 1.62em）：末页只要有半页空余就能容纳；放不下才另起一页（该页约 65% 填充）。实测某套因此从 15 页收回 **14 页、末页 94.5%**。
- **纯文字客观卷（无演算需求）行数要更少**：广州辅警卷试过 27 → 10 → **8 行**（行高同时收到 1.32em）才收进末页，末页填充率 90—94%。**行数与行高是两个旋钮，要联调**，别只改一个。
- **宽松版（行高 1.55em）＋ 含主观题的卷：`DRAFT_LINES = 16`**（2026-09-23 普宁卷实测）。这类卷的结构是「主观题作答区跨页 → 末页只剩作答区尾部 + 结束语 + 草稿区」，末页可用高度往往只剩 380pt 左右：
  - `N=24`（块高约 434pt）**放不下** → 草稿区整块跳到新的一页，倒数第二页只有 49%、最后多出一页（三套卷页数不齐：16/15/15）。
  - `N=20`（约 396pt）**仍差 14pt**，依旧跳页。
  - `N=16`（约 350pt）**刚好**，三套统一 15 页，末页填充率 97%/76%/79%。
  - **教训：块高要按「实测剩余高度」倒推，别按经验值拍。** 先渲一版量出「倒数第二页最低点 y」与「版心底 y」的差，再定行数。差 14pt 也是差，`break-inside: avoid` 不会给你将就的余地。
- **答案册末页只有「一行小字说明 + 结束语」时填充率可以低到 33%，属正常**：这一小块（`.revwrap`）整块锁页，若前一页余量不足就整页跳过去。**不要为了填满末页把它劈成两页**——劈开比留白更难看。同理，答案册里的 `.explain` / `.ztans` 也各自 `break-inside: avoid`，会造成 70% 左右的单页留白，这是"解析块不跨页"的代价，属可接受范围。
- 答案册末尾结构（简约版）：**逐题解析结束 → `.revline` 一行小字（时效与合规口径，如「本册时政更新至 YYYY 年 M 月；未引用本次招聘公告中的任何具体信息」）→ 「—— 本 册 到 此 结 束 ——」**。不要再恢复成「修订与说明」红框大栏目。
- **小字说明与结束语要一起包进 `.revwrap` 整块锁页**：否则结束语会被单独顶到新的一页（该页填充率仅 1.3%）：
  ```python
  def render_rev():
      return ('<div class="revwrap">'
              f'<div class="revline">{REVISION}</div>'
              '<div class="cend2">—— 本 册 到 此 结 束 ——</div>'
              '</div>')
  ```
  ```css
  .revwrap { break-inside: avoid; page-break-inside: avoid; }
  .revline { font-size: 9.2pt; color: #6b7684; line-height: 1.8; text-align: center; margin: 16pt 6pt 4pt; }
  ```
- **判定标准**：逐页算填充率 `(内容最低点 − 页顶)/(版心高)`，要求**没有页面 < 55%**（图形题锁页造成的 60% 出头属正常）。
- **正文底与页脚要留白**：页脚线画在 `h-37` 附近（`y = h-26` 基线上方 11pt），逐页扫一遍 `max(block[3]) < 800`（A4/842pt），超过 800 就会压页脚。

## 六·十三、Word（.docx）版：必须从数据源直出，不要转 PDF

用户要"Word 版"时，**绝大多数是要能编辑/复制题目的源文件**，不是打印件。

**铁律：不要用 PDF→docx 转换**（得到的是死文本或整页图片，完全不可编辑）。既然出题时已经持有结构化数据（`QS` / `SL` / `FIG_FILES`），就用 **python-docx 从同一份数据直出**——题干、选项、解析全部是原生段落文本，与 PDF 天然同源、零差错。

```bash
pip install python-docx        # 1.2.0 已验证
```

**中文与排版**
- 中文字体必须写 `w:eastAsia`，否则 Word 里回落到默认字体：
  ```python
  from docx.oxml.ns import qn
  rPr = run._element.get_or_add_rPr(); rf = rPr.get_or_add_rFonts()
  rf.set(qn('w:ascii'), 'Times New Roman'); rf.set(qn('w:hAnsi'), 'Times New Roman')
  rf.set(qn('w:eastAsia'), '宋体')     # 标题用「黑体」
  ```
- 段落底纹 / 边框用 `w:shd`、`w:pBdr`（模块标题=藏青底白字，作答区=下边框空段落，行距设固定值让线条有间距）。
- **选项两列**：短选项（≤18 字）用制表位并排 —— `pf.tab_stops.add_tab_stop(Cm(8.3))`，文本写成 `A. xxx\tB. yyy`；长选项各占一行。题号用悬挂缩进（`left_indent=0.75cm` + `first_line_indent=-0.75cm`）。
- **页码用域**，且**必须带 `separate` + 缓存值**，否则不刷新域的阅读器显示空白：
  ```
  begin → instrText(" PAGE ") → separate → <w:t>1</w:t> → end
  ```
- 交付前用 `doc.inline_shapes` 数插图、用 `p.tables` 数表格，别只看文件大小。

**图形与图表**
- 图形题 SVG 文件里**并列了两个 `<svg>`**（`class="figseq"` 题干图 + `class="figopt"` 选项图，有的题只有后者）——**直接 `pymupdf.open()` 会把两张图叠在一起**，必须先拆：
  ```python
  import re, pymupdf
  parts = re.findall(r'<svg\b.*?</svg>', Path(f).read_text(encoding='utf-8'), re.S)
  # 每个 part 写成临时 .svg → pymupdf.open() → get_pixmap(dpi=300) → PNG → add_picture
  ```
- 资料分析的 `chart` 本身就是 SVG 字符串，同样转 300dpi PNG。插图宽度：题干图 ≤13cm、选项图 ≤11.5cm、图表 ≤13.5cm。
- **多套卷时，PNG 文件名与内存缓存键都必须带「SVG 内容 md5」**（内容寻址），不能只用题号或 `'chart'` 这类固定 tag：
  ```python
  h = hashlib.md5(svg_text.encode('utf-8')).hexdigest()[:10]
  key = (tag, h, dpi)                      # 缓存键含 h
  out = ASSETS / f'{tag}_{h}.png'          # 文件名含 h
  ```
  **为什么必须**：图形推理题的全局题号在每套里都是同一批（如 47—51），若 tag 只用题号、缓存键只含 `(tag, dpi)`，第 2、3 套会**直接命中第 1 套的缓存**，把第 1 套的图形印到第 2、3 套里；图表 tag 固定为 `'chart'` 时同样会串。此坑**只看插图张数查不出来**（张数完全正常）。
- **校验要按内容比对，不能只数张数**：把期望的 SVG 逐张用同一管线渲成 PNG 取 md5，与 docx 内 `word/media/` 的 md5 集合逐一比对；再跨套断言「两两重合 ≤ 1 张」。
  ```python
  import zipfile, hashlib
  got = {hashlib.md5(zipfile.ZipFile(f).read(n)).hexdigest()
         for n in zipfile.ZipFile(f).namelist() if n.startswith('word/media/')}
  # got 必须 == 期望集合；且 任意两套交集 ≤ 1（仅可能撞上同一张图表）
  ```

**校验（读回文档逐项断言）**
```python
from docx import Document
d = Document(path)
body = '\n'.join(p.text for p in d.paragraphs)
# 题号连续、选项齐全、分值表、答案速查 100 条、逐题解析 100 条、
# 速查与解析一致、标答与数据源一致、解析末句「故选X」、考点标签数、插图数
```
注意 `'故选 A'` 在数据里**带空格**，判定要用 `re.search(r'故选\s*' + ans, seg)`，不能写 `f'故选{ans}'`。按题号切块核对末句：
```python
blocks = re.split(r'(?m)^(\d{1,3})\. 【答案】', body)   # [前言, no1, seg1, no2, seg2, ...]
```

**验证渲染效果的现实条件**（本机无 LibreOffice / pandoc）：
- `qlmanage -t` 在无 GUI 会话下**直接失败**（`sandbox initialization failed`，加沙箱豁免也一样）。
- `textutil -convert html` 能用，但**会丢图片和段落边框**（`<img>` 计数为 0）——只能用来目检文字与表格结构；插图、作答区下划线改用 python-docx 读 XML 或直接看生成的 PNG 验证。

**docx 的"逐字节比对"会误报**：docx 是 zip，容器里存了每个条目的修改时间与中央目录顺序，**同一份内容重新生成一次，md5 必然不同**（长度却完全相同）。所以判断"重建产物是否忠实"要按内部条目比：
```python
import zipfile
za, zb = zipfile.ZipFile(old), zipfile.ZipFile(new)
diff = [n for n in za.namelist() if n in zb.namelist() and za.read(n) != zb.read(n)]
assert not diff and len(za.namelist()) == len(zb.namelist())
```
同理，PDF 的"逐字节比对"要先剔除随机量：`/ID[<..><..>]`（文档标识）与 `D:YYYYMMDDHHmmSS+08'00'`（创建时间），归一化后再比才是有效的忠实性证明（本次 6 份 PDF 归一化后 6/6 逐字节一致）。

**归档**：Word 放独立目录（如 `…五套（Word版）/`），内部按原分类建同样的子目录；两个交付目录都要清掉 `.DS_Store`。

## 六·十四、去 AI 味：解析要像出版社写的（用户 2026-09-23 反馈"AI 味道明显"后固化）

**目标**：解析读起来像中公/华图正式出版物里的解析，而不是模型生成的说明文。

### 14.1 禁用写法清单（写进 `BANK_SPEC.md`，出现即退稿）

| 类别 | 禁止 | 说明 |
|---|---|---|
| 模板起手 | 「本题考查」「本题旨在考查」「本题考查考生对…的掌握」 | 全题库出现次数 **≤ 总题数 10%**，且不得连续两题都用 |
| 模板收尾 | 「综上所述」「由此可见」「因此本题选择」 | 客观题末句**统一**为 `故选 X。`（判断题 `选 √。`/`选 ×。`），别无花样 |
| 四字格堆砌 | 「意义重大」「影响深远」「提供了有力支撑」「具有里程碑意义」「彰显了…」「充分体现了…」 | 一条都不许有 |
| 排比升华 | 「既…又…，不仅…而且…，更是…」三段式升华 | 解析不是申论 |
| 段落等长 | 每题解析都写 3—4 行、字数都差不多 | 必须**长短交错** |
| 空洞评价 | 「这一政策体现了党和政府以人民为中心的发展思想」 | 与选项判定无关的感想，删 |
| 元话语 | 「需要注意的是」「值得一提的是」「需要指出的是」 | 出版物很少这么写 |

### 14.2 正面写法：解析长度必须长短交错

- 长度区间 **30—200 字**，中位数约 70 字。
- **简单题 1—2 句直接给结论**（如"2026 年为建军 99 周年，建军 100 周年要到 2027 年。故选 B。"），**不要为了凑长度写废话**。
- **干扰项要逐个点破**（"A 项环境保护法是单行法律，B、D 项分别是长江、黄河流域的专项法律，都不是法典。故选 C。"）——这是解析**最有价值**的部分，也是最能显"专业"的地方。
- **解析与题干呼应**，可以引用题干里的具体表述（"先摸底、后定方案，讲的是把实际情况当作出发点"），而不是抽象复述。

### 14.3 出厂检测脚本

```python
BAN_PHRASES = ['本题考查', '本题旨在考查', '综上所述', '由此可见', '意义重大',
               '影响深远', '提供了有力支撑', '具有里程碑意义', '彰显了',
               '充分体现了', '需要注意的是', '值得一提的是', '需要指出的是']

# ① 禁用词：全库零命中
for q in ALL:
    blob = q.get('parse', '') + q.get('ref', '') + q.get('points', '')
    for p in BAN_PHRASES:
        assert p not in blob, f'Q{q["no"]} 命中 AI 味词：{p}'

# ② 模板起手占比 ≤ 10%
n = sum(1 for q in ALL if q.get('parse', '').startswith('本题考查'))
assert n / len(ALL) <= 0.10, f'模板起手占比 {n/len(ALL):.0%}'

# ③ 长度必须交错（不能全部落在同一区间）
L = [len(q['parse']) for q in ALL if q.get('parse')]
import statistics
assert max(L) - min(L) > 60, '解析长度过于均匀'
assert 30 <= statistics.median(L) <= 200, f'解析长度中位数 {statistics.median(L)} 越界'

# ④ 相邻重复句（老坑，判断题最易犯）
for q in ALL:
    assert not re.search(r'([\u4e00-\u9fa5，、；：]{4,14}。)\1', q.get('parse', ''))
```

⚠️ **检测必须扫 PDF 层，不能只扫数据源**——渲染层的模板可能自己带出 AI 味（例如渲染函数给每道题都加了固定的引导句）。做法：把 PDF 全页文本压平后 `flat.count(...)` 逐词扫一遍。

## 七、命名规范

- **只建一层文件夹** = 公告核心内容（如「2026肇庆市高校毕业生基层公共就业创业服务岗位招募」），**PDF 直接放进去**。
- **不要建「综合知识」这类单一学科层**——卷子只有一门课时，多这一层没有任何区分作用，纯属多余（用户 2026-09-17 明确要求，之后一律不建）。
- **只有确有 ≥2 个并列科目时才建学科子目录**，且目录名用真实科目名。已有先例：选调 `行政职业能力测验/`＋`申论/`＋`参考答案及解析/`；茂南 `公共基础知识/`＋`计算机基础能力测试/`。
- 归档脚本里的输出路径常量（`DELIV` / `OUT`）**别写死学科层**，否则下次重建又会把它带回来。
- 文件 = `年份+考试简称+冲刺卷+序号`，如 `2026肇庆基层就业创业服务岗冲刺卷（一）.pdf`
- 答案文件 = 同名 + `参考答案及解析`
- **文件内标题与文件名一致**

## 七·五、源目录被误删后怎么完整复原（会话记录回放）

**先说纪律（比复原方法更重要）**：删除/移动一律写成 `cd "<绝对路径>" && rm -rf "<相对目标>"`，或直接用 Python `shutil` + `assert os.path.isdir(绝对路径)` 兜底。**绝不要写 `rm -rf "../$(basename "$PWD")"` 这类依赖当前工作目录的相对路径**——当它和前面的命令串在一行、而 shell 已被 `cd` 走时，删掉的就是整个项目目录（真实事故：`_build/shantou2026` 被整目录删除，`archive_docx.py` 还在别的目录下误建了一个交付目录）。

**复原原理**：每次会话的完整工具调用都落盘在
`~/.workbuddy-ai/projects/<项目名>/<会话ID>.jsonl`（主代理）与同目录 `subagents/*.jsonl`（子代理）。
记录形如 `{"type":"function_call","name":"Write","arguments":"{...}"}` ——
⚠️ **`arguments` 是 JSON 字符串**（要再 `json.loads` 一次），`name`/`arguments` 在**顶层**，按嵌套 `input` 去找会一条都提取不到。

**复原三步**
1. **重建骨架**：从记录里找出最初的 `cp -R` 命令原样执行（如 `cp -R ns2026 shantou2026`），再按当时的 `rm -f` 删掉要重写的文件（`bank_*.py`、`ziliao_ns.py`、`genfigs_ns.py`）与产物目录（`figs html pdf docx docx_assets`）。**只有"第一个操作是 Edit"的文件才需要这步**（初始态＝骨架拷贝）；第一个操作是 Write 的会被直接覆盖。
2. **按时间回放**：全部 `Write`（写 `content`）与 `Edit`（`old_string`→`new_string`，注意 `replace_all`）按 `timestamp` 排序后依次执行。
3. **验证**：`py_compile` 全部 → 跑组卷自检（题量/配比/答案分布应与事故前报告逐项吻合）→ 重跑 `render.py` 并与**已交付 PDF** 做归一化逐字节比对。

**必须知道的细节**
- 回放中少量 `Edit` 报 `OLD_NOT_FOUND` **属正常**：多是子代理对同一处文字连续改了几次，前一次的 `old_string` 已被同组后续 Edit 覆盖。判断方法：把它的 `new_string` 拿去当前文件里搜，**意图已达成就不用补**。
- `~/.workbuddy-ai/file-history/<会话ID>/` 的快照是**改动前**版本（多半就是从骨架拷来的原样），**不能当最终态用**。
- 交付物在交付目录里，删 `_build` 不会波及；**先确认交付物完好**，再决定要不要花力气复原源文件。
- 复原完清掉中间产物（`html/ pdf/ docx/ docx_assets/ figs/ _chk/ __pycache__/`），只留脚本与 `.md`/`.css`。

## 八、已知坑

- 竖排"密封线"字段区（writing-mode:vertical-rl + column-reverse）在卷首固定高度内会**溢出丢字** → 改用横向信息栏 + 横向虚线密封线。
- 无头浏览器渲染前**必须**把含中文/空格的路径 `as_uri()` 编码，否则打不开。
- **Edge 无头会偶发 `SIGTRAP`（信号 5）崩溃**：崩溃会**中断渲染循环**，导致该套 PDF **已写出但没走到盖章步骤 → 没有页脚和页码**。两道保险：① `html_to_pdf` 包 3 次重试（失败 `time.sleep(2)` 后再试）；② **崩溃后必须逐份核对页脚文字**（`page.get_textbox(Rect(0, 795, W, H))` 里要有署名和「第 N 页 / 共 M 页」），**不能只看文件存在**。沙箱拦截日志里出现 `Microsoft Edge-headless/...VariationsSeed*` 之类的 file-write-unlink 是常态，不一定致命。
- **解析里不得出现相邻重复句**（如「表述正确。表述正确。」「表述错误。表述错误。」）：判断题解析最易犯，多是子代理起草时把结论写了两遍。断言：
  ```python
  re.search(r'([\u4e00-\u9fa5，、；：]{4,14}。)\1', parse)          # 任意相邻重复句
  parse.count('表述正确。') > 1 or parse.count('表述错误。') > 1     # 判断题专用
  ```
- **卷内标题 / 页脚套号用中文数字**，与文件名「（一）」一致（满足「文件内标题与文件名一致」）。用一个 `CN = ['一','二','三']` 常量贯穿 HTML 生成、PDF 盖章、Word 生成三处，别各写各的。
- **长考试名的首页标题会折行**：`h1.title` 用 22pt + `letter-spacing:3pt` 时，「2026 广州市公安局招聘警务辅助人员（第二次）」会断成「…（第二 / 次）」，很难看。做法：**字号降到 19pt、字距收到 1.2pt**，并在出厂总检里断言首页第 2 行是完整单行标题。考试名超过 20 字的一律按此调，别等目检才发现。
- **Word 交付文件名要与 PDF 版仅扩展名不同**（PDF 用「（一）」而 Word 用「（1）」会被归档脚本判为 MISS）。归档脚本的取数逻辑与 `verify_docx.py` 的文件名常量要一起改。
- 不要在正文出现"AI生成""合理推断"等字样；难度定位**中上**，题干取**中长**，避免短题干。
- 时政题不要把"某条未经证实的说法"当事实（例如易错的建设周年数），拿不准就换题。
- **只给一套卷做"答案精编/重排"时也要走完整核验流程**：老答案册的字母错位极常见，逐题重写解析比修修补补更快更稳。
- 答案解析册固定结构（**2026-09-24 简化**）：**①答案速查（表格，按部分分组，10题一行）②逐题解析（题号徽章＋答案徽章＋考点标签＋解析）③主观题参考答案与评分要点**。原「修订与说明」红框栏目**整块删除**，压成结束语上方的一行居中小字（时政月份、跨套查重、未引用公告信息三件事一句话带过）——大段"出厂总检通过…"式说明是 AI 味的自我表扬，客户不需要，且独立栏目会在末页制造 20% 填充的寡妇页。
- **渲染脚本拷贝 CSS 必须每次覆盖**，写成 `if not css_dst.exists(): shutil.copy(...)` 会导致"改了样式、PDF 纹丝不动"，排查半天。
- **同一文件并行发两个 Edit 会静默丢更新**（老坑，反复踩）。必须串行提交，改完立刻读回确认。
- **选项键顺序必须卡死**（曾混进已交付 PDF，自动化检查漏过）：`balance._swap` 用 `dict[mapping.get(k, k)] = v` 重建选项会把置换后的插入顺序带出来，卷面印成 `B. / A. / C. / D.`。置换后必须重排：
  ```python
  tmp = {}
  for k, v in opts.items(): tmp[mapping.get(k, k)] = v
  new_opts = {k: tmp[k] for k in 'ABCD' if k in tmp}   # 关键
  ```
  并在组卷自检里断言 `list(q['opts']) == ['A','B','C','D']`。
- **中文直引号全角化必须走 `tokenize`**：卷面出现 ASCII `"` 很难看，但按行盲替 `"`→`“”` 会把 Python 字符串定界符一起换掉 → `SyntaxError: invalid character '“' (U+201C)`。正确做法：
  ```python
  import tokenize, io
  toks = list(tokenize.generate_tokens(io.StringIO(src).readline))
  # 只处理 token.type == tokenize.STRING 的 token.string 内部，交替替换 " → “ / ”
  out = tokenize.untokenize(new_toks)
  compile(out, '<s>', 'exec')   # 把关；失败则保留原样
  ```
  ⚠️ **但 `tokenize` 只对「语法正确」的文件有效**。数据文件里一旦把中文引号写成 ASCII 双引号（如 `""景德镇手工瓷业遗存""`），Python 会把它解析成「空字符串＋标识符」，文件本身已 `SyntaxError`，此时 `tokenize.generate_tokens` 直接抛错、修复无从下手。**正确顺序是先修引号、再 tokenize**，用「按字符扫描 + 启发式定界符判定」：
  ```python
  # 1) 先保护三引号块（HTML 属性里的 " 不能动）与字典键
  src = re.sub(r'""".*?"""', keep, src, flags=re.S)
  src = re.sub(r"'''.*?'''", keep, src, flags=re.S)
  src = re.sub(r'"([ABCD])":', lambda m: '\x01'+m.group(1)+'\x02:', src)
  # 2) 逐字符判断每个 " 是不是定界符；不是就按出现顺序交替换成 “ ”
  def is_delim(s, i):
      p, gp = nb(s, i, -1); n, gn = nb(s, i, 1)   # nb 取「前/后一个非空白字符」及其间空白
      if p == '"' and '\n' in gp: return True      # 跨行隐式拼接的边界
      if n == '"' and '\n' in gn: return True
      if p in ':,([{': return True                 # 值起始 / 参数起始
      if n in ',})]': return True                  # 值结束
      return False
  # 3) 还原占位符后 compile() 把关
  ```
  三条规则缺一不可：漏掉「跨行拼接边界」会把 `"…\n" "…\n"` 多行拼接串的收尾引号误换成中文引号；漏掉「三引号块保护」会把 HTML 的 `class="hl"` 一起换掉。
- **无头 Edge 渲染会被沙箱拦**：批量渲染到中途报 `CalledProcessError ... died with <Signals.SIGSEGV: 11>`，stderr 显示拒绝写 `~/Library/Application Support/Microsoft Edge-headless/...`（上千项）。这不是 Edge 的错，是沙箱挡了它写自身 profile——**加 `dangerouslyDisableSandbox` 重跑即可**。注意：即使返回码非 0（沙箱在渲染结束后才拦截 profile 写入），**PDF 往往已经正常生成**，先 `ls` 确认产物再决定是否重跑。
- **数字推理题干格式要统一**：存量题与新增题常写成两种样子（`2, 6, 12, 20, 30, __，括号内应填：` vs `1，2，6，15，31，（　　）`）。统一为后者：全角逗号 + 全角括号 + `数字推理：观察下列数列的规律，选出括号内应填的数字：`。
- **数值选项必须升序，并写成断言**（真题惯例）。适用于**数字推理**与**资料分析**（这两类也因此不参与选项均衡器）。易漏点：分数型选项（`6/35, 6/37, 6/39, 7/37` 实际不是升序——6/39 < 6/37 < 6/35）。建议在组卷自检里加：
  ```python
  def _chk_num_ascending(q):
      import re; from fractions import Fraction
      cores, sufs = [], []
      for L in 'ABCD':
          s = str(q['opts'][L]).strip().replace(' ', '')
          m = re.fullmatch(r'(\d+)\s*/\s*(\d+)', s)
          if m: cores.append(Fraction(int(m.group(1)), int(m.group(2)))); sufs.append('/'); continue
          m = re.fullmatch(r'(\d+(?:\.\d+)?)(.*)', s)
          if not m: return                      # 含文字，跳过
          cores.append(Fraction(m.group(1))); sufs.append(m.group(2))
      if len(set(sufs)) != 1: return            # 量纲不一致（万亿元 vs 亿元），跳过
      assert cores == sorted(cores), f"Q{q['no']} 数值选项未升序"
  ```
  改选项顺序时**必须同步改 `ans` 与解析末句**（曾出现 A→B）。
- **题干与选项跨页分离**：`.q` 上的分页属性管不住选项（`.opts` 是兄弟节点）。**⚠️ 本条早先的写法已被证伪，勿再照抄**：`page-break-inside: avoid` 在 Chromium/Edge **不生效**，而 `page-break-after: avoid` 会串成长链把每道题顶到次页。正确写法见六·十二：
  ```css
  .q   { break-inside: avoid; page-break-inside: avoid; }   /* 不要加 break-after */
  .opts{ break-before: avoid; break-inside: avoid; }
  ```
  修好后页数**可能变化**（属正常，别急着判错）。交付前用脚本扫一遍孤题：逐页取最后一个题号，看该页其后的 `A./B./C./D.` 是否满 4 个（图形推理题无文字选项，按题号区间跳过）。
- 答案速查必须与逐题解析**同源生成**；`verify_all.py` 出厂总检要同时卡 HTML 层与 PDF 层（答案速查条数齐全、卷面题号齐全、首页无「考情说明／模块分布」残留、AI 痕迹与友商机构名红线）。
- **申论答案的栏目标题会印两遍**（真实事故）：数据里 `score_points[0]` / `ref_answer[0]` 常自带「【评分要点】」「【参考答案】」前缀——有的是「标题+内容」合一，有的是**纯标题行**。渲染层又加一次标题，就变成每题两个「【评分要点】」。统一用 `_strip_head()` 处理：纯标题行返回空串（跳过），「标题+内容」剥掉前缀保留内容。**修完必须重渲 PDF**，Word 版同样处理。
- **交付目录路径必须自动探测，不要写死**：用户会改名（`…冲刺卷` → `…冲刺卷五套`），写死路径的 `archive.py` / `verify_all.py` 会当场失效（症状：校验报「只有 0 份」，且归档会**另建一个旧名目录**）。做法：按关键词遍历工作区一级目录，PDF 目录取「含关键词且**不含「Word」**」的那个。
- **`Path.mkdir(exist_ok=True)` 在某些沙箱 shim 下报 `PermissionError: EEXIST`**（`exist_ok` 不生效）——改成 `if not d.exists(): d.mkdir()`。
- Grep 工具对某些构建目录下的文件会返回空结果，查内容改用 python 读文件更可靠。
- 数据文件里中文引号嵌套（`'从'制造大省'迈向…'`）会直接 SyntaxError，内部引用一律换成「」『』。
- 并发生成的子代理在长任务里容易 502 / ENOTFOUND，关键卷次自己写更稳；真要用子代理就让它只产出"素材.md"，主代理再据以出题。
