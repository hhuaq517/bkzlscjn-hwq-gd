# 考编真题还原与试卷排版

把用户给的「不完整试卷 / 部分考情 / 模糊截图」还原成一份印刷级 PDF 试卷（题目 + 答案 + 解析）。

## 交付规范（默认，用户另有说明则以其为准）

1. 先检索该场考试的**最新考情**（公告、科目、题型题量、时长分值），再动手还原；难度定位**中上**。
   **定结构优先自己算，别急着问用户。** 先看备注里有没有「大学内容约 30 多分」这类**占比线索**，
   按「题量×分值＝满分」反推；能自洽就直接开做——生物卷备注写「大学内容约占 30 多分」，
   18 道学科题里大学内容 8 题，每题 4 分正好 32 分，据此定 19 单选×4＋4 多选×6＝100 分/23 题，
   一次定死。只有当回忆合计与满分怎么都配不平、或占比线索也缺失时，才问用户。
   定完把「题量×分值＝满分」写进 check 断言。
2. PDF 结构：**试卷大标题 → 简明考情（5 行表＋一段小字说明）→ 考生须知（4 条）＋答题卡 →
   试卷正文 → 配套答案解析**。除「参考答案及解析」外**一律通排**——不设封面页、不设独立须知页，
   详见下节「卷面从简」。答案解析**必须与正文分页**，不共页。

### 卷面从简（2026-09-20 项目负责人明确要求，新交付一律照此）

**卷首要薄，题目要早——第一页就得看见题。**

- 卷首**不单独占一页**。第一页＝标题＋简明考情＋考生须知＋答题卡＋正文开头，全部通栏接排。
- 简明考情**只留 5 行**：考试名称／招录批次／笔试内容／题型题量／试卷满分。
  **删掉「分值构成表」和「题型题量模块表」**——分值已写在各大题标题里，模块表纯占地方。
- **去掉密封线**（左侧竖排姓名/准考证号那套）。它是整页 `display:flex` 的产物，
  一旦卷首不再独占一页就会跨页撕裂；去掉后正文通栏，第一页能多塞好几道题。
- 考生须知压到 4 条；答题卡改 **10 列 × 5 行、格高 8.6mm**（整块约 80mm，与第一页同页）。
- **除「参考答案及解析」外，任何 section 都不要 `page-break-before: always`**。
- 间距收紧，否则主观题尾块被挤到新页、白扔一页：
  `h2.part-h2` margin-top 2.8mm、`.part-note` margin-bottom 1.8mm、
  `.subj` margin-bottom 3.2mm、`.subj-h` margin-top 2mm。
- **出厂前量各页剩余高度**，除末页外任何页 `free_mm > 60` 就是分页没排好：

```python
import pymupdf
d = pymupdf.open('out.pdf')
for i in range(d.page_count):
    low = max((x[3] for x in d[i].get_text('blocks')), default=0)
    print('p%d free_mm=%.1f' % (i+1, (d[i].rect.height - 39.7 - low) / 72 * 25.4))
```

  实测效果：珠海辅警那册老版式 9 页（封面 1＋须知 1＋正文 3＋解析 4），
  改从简后 7 页（第一页＝考情＋12 道题），零空白页。

3. **增补原则**：只补全"缺失/不完整"的题干与选项；原卷已完整就只优化排版，不增补、不硬加时政和市情。
   需说明来源时统一写"考生回忆，仅供参考"，**禁止**出现"生成""合理补充"等字眼。
4. **用户明确要求"补足到 N 分/扩题"时**（此时才允许自拟新题）：
   - 先按官方公告的分值结构定题量（如 100 分＝60单选×1＋10多选×2＋20判断×1），把原题嵌入按学科分组的连续题号区间。
   - **新题选项顺序必须主动打匀**：自拟题极易扎堆到 B，首版实测新增 30 题里 B 占 13、D 为 0。
     概念型题可自由换序；数值型选项按升序排，答案位置天然分布，不必强改。目标整体 A/B/C/D ≈ 各 15。
   - 出 PDF 前先跑校验脚本：题量、每题选项数是否 4 项、答案字母是否在 ABCD 内、答案分布是否失衡。
5. 不要有 AI 痕迹：不要出现"以下为AI生成""合理推断"等表述；版式贴近常规印刷试卷。

### 打匀答案的最省事做法：渲染期重排 + 解析字母同步映射

手工换序 100 道题会累死人，且极易漏改解析。实测最稳的是**在渲染层做一次置换**：

1. 写一个 `balance.py`：导入 content，按题号顺序列出全部题目；标出「顺序固定」的题
   （数值型选项按升序排的题，答案位置由数值大小天然决定）；给剩余「自由题」逐题分配目标字母，
   分配规则＝**优先补当前缺口最大的字母，且不允许连出三题同号**；最后输出一张
   `PERM = {("模块", 题序): [新位置→原位置]} 的置换表`。置换用「交换当前答案位与目标位」即可，最小改动。
   实测 100 题可从 A37/B43/C17/D3 一次拉到 25/25/25/25。
2. `build.py` 里加 `perm_opts(key, opts, ans)`：按 PERM 重排选项，答案字母换算为 `LETTERS[perm.index(旧序号)]`。
3. **关键一步——解析里的选项字母必须同步换算**，否则「只有 B 项符合」会指到错项。加
   `remap_letters(text, key)`，用两条正则：
   - 并列引用：`((?:[ABCD]、)+[ABCD])((?:两|三|四)项)` → 逐个字母映射后再拼回；
   - 单字母引用：`(?<![ABCD]、)([ABCD])\s*(?=项)` → 映射。
   负向后顾 `(?<![ABCD]、)` 是为了**避免并列里的末字母被二次映射**。
   只匹配「X项」，就不会误伤逻辑题解析里的命题符号（如「只有A，才B」表示A是B的必要条件，即B→A）。

   **⚠️ 中英混排的空格陷阱（2026-09-20 实测踩过）**：中文排版习惯在拉丁字母与汉字间加空格，
   解析里写的是「与 B 项一致」而非「与B项一致」。若正则写成 `([ABCD])(?=项)`，**一个字母都匹配不到，
   而且不会报错**——check 只校验答案字母合法性，不校验解析与答案是否自洽，于是 PDF 出来
   答案标 D、解析仍写「与 B 项一致」，整卷错位却静默通过，只有逐页目检才能发现。
   正则必须写成 `([ABCD])\s*(?=项)`（`\s` 放在 lookahead 内，空格不被消费，替换后原排版保留）。
   **并且出片前加一道断言**：解析里若出现「X项」，则答案字母必须出现在这些引用里——
   `assert not refs or q["ans"] in refs`，否则直接 fail。这道断言比目检更早拦住错误。
4. 自拟解析**别写死选项的排列顺序**（如「四个选项依次为正五边形、正六边形、正七边形」），
   重排后必然错。改成按内容描述（「四个选项中只有正七边形符合」）。
5. 并列引用重排后可能出现「B、A、D三项」这种别扭顺序——原文直接写「其余三项」最省事。

### 打匀的四个进阶坑（2026-09-20 深圳基层岗 90 题全客观卷实测）

1. **纯贪心会产出完美的 ABCD 循环。** 只按「补当前缺口最大的字母」逐题分配，实测把第 31—45 题
   和 46—60 题渲染成 `B C D A B C D A …` 两段等差数列——比答案扎堆更假，一眼看出是机器排的。
   解法：评分里加**随机抖动**（幅度取全卷缺口权重的同量级），再对**种子做一次搜索**，
   用固定种子保证可复现。评价指标除「全卷极差」「最长连号」外必须加**「周期4重合率」**
   ＝`seq[i]==seq[i-4]` 的比例（随机基线约 0.25，完美循环为 1.0），取该值最小的一组。
   本次在 1200 个种子里筛出「极差 1／最长连号 2／周期4重合率 0.209」的一组。
   另：评分要**模块内缺口为主、全卷缺口兜底**（权重约 1:2.5）。只优化全卷会让某个 8 题模块
   挤进 5 个同号字母；只优化模块又会让全卷 D 少 4 个。
2. **数值型选项模块根本没法置换。** 数字推理、数学运算、资料分析的选项必须升序，
   强行置换会出现「96、93、95、94」这种破序。这些模块的答案位置由数值大小天然锁死，
   本次渲染成 `B B C C D B B C C B`。**正确解法是改干扰项数值、把正确项挪到目标位置**
   （答案 95 想落在 C 位就写 `93、94、95、96`，想落 A 位就写 `95、96、97、98`）。
   改完**别手改 ans 字母**——写个脚本按「正确项内容」反查它在新选项里的下标、自动改写 `ans`，
   本次一次改 22 题零出错。
3. **check.py 的答案分布统计必须应用 PERM。** 只统计 `content.py` 里的原始 `ans`，
   会永远报「分布失衡」（本次原始 48/13/16/13，置换后其实是 23/23/22/22）。
   在 check 里加个 `ans_of(q)` 走一遍置换表再统计。
4. **图形推理的选项也要参与置换。** `render_fig_opts` 若不按 perm 重排，图推答案就固定不动，
   且 `render_exp` 算出的答案字母会与题面标号对不上。让 `apply_perm()` 同时作用于
   `opts` 与 `opt_figs` 两条分支即可。
5. **解析里的「第X项」序数引用要先批量转成「A项」形式**，否则 `remap_letters` 的正则
   （只认 `X项`）一个都匹配不到。转换时**必须排除"数列的项"**——第68题
   「从第三项起，每一项等于前两项之和」差点被误改成「从D项起」，逐行 grep 复核可拦住。
6. **加一条一致性提示**：解析若引用了选项字母，答案字母通常应出现在其中。
   把「解析只提到 X、答案却是 Y」的题列成清单（**只提示不报错**），交付前人工过一遍——
   本次筛出 5 题，全是「排除法式」解析（只讲错项、不点正确项），属正常，但值得确认。

## 关键前提：先判断素材能不能读

**低清截图会让模型产生"看起来很合理但实际错误"的臆读**，这是本任务最大的坑。
拿到图片先做分辨率评估，不要凭第一眼印象直接开写。

```bash
# 1) 看尺寸与正文字高
python -c "
from PIL import Image; import numpy as np
im=Image.open('x.jpg').convert('L'); a=np.asarray(im).astype(int)
ink=(a<150).sum(axis=1); rows=[]; cur=None
for i,v in enumerate(ink):
    if v>2:
        cur=[i,i] if cur is None else [cur[0],i]
    else:
        if cur: rows.append(cur); cur=None
if cur: rows.append(cur)
print('size',im.size,'lines',len(rows))
import statistics; print('median line height', statistics.median([r[1]-r[0]+1 for r in rows]))
"
```

- **正文行高 < 6px** → 不可靠识别，**必须换源**，不要硬做。
- 再用 macOS Vision OCR 跑一遍原图：**成句即可用；全是乱码就换源**。

### 长截图型 PDF：先查有没有「缺页」，再动手

手机/电脑长截图（iShot 等）导出的 PDF 常常是 **1 页、内嵌一张超高图、`get_text()` 返回空**。
不要按普通 PDF 处理。先看 `page.rect` 的宽高比：比值 > 5 就是长截图。

读法（实测有效）：**切块 → 逐块 OCR → 关键行放大目检**。

```python
# 1) 导出内嵌大图
pix = pymupdf.Pixmap(doc, doc[0].get_images(full=True)[0][0]); pix.save('src.png')
# 2) 切成 ~2000px 高、带 120px 重叠的块，逐块 vision_ocr
# 3) 目检：Read 工具直接看 png，OCR 只用来定位
```

**缺页判定——这是最容易漏掉、也最要命的坑。** 这类截图里通常每页页脚有个深色圆角徽标
（`N/25` 之类的页码），落在页间留白里。用行墨迹剖面就能把全部徽标揪出来：

```python
# 找「大空白带(~250-350px) + 徽标 + 小空白带(~120px)」的三段式
runs = [(a,b) for a,b in blank_runs if b-a+1 > 60]   # 见上面的 ink 剖面
# 对每个候选区间裁 (0, a-30, 600, b+30) 交给 vision_ocr，读出页码
```

- **页码跳号 = 原卷缺页**（实测遇到 `1,2,3,5,6,7,8,9`——第 4 页整页丢失）。
- **⚠️ 但「徽标缺失」不等于「缺页」**（2026-09-21 中远英语卷实测踩过）：那份 6 页截图只检出
  `1/6`、`2/6`、`4/6`、`6/6` 四个徽标，看着像丢了第 3、5 页，实际正文 Section A→D 完全连续、
  无任何断句。**必须用「行墨迹剖面」交叉验证**：把每行的墨迹行区间求出来，看相邻行间距，
  正常行距 ~140–150px，**>300px 的才是页间空白带**。若各空白带位置与徽标位置一一对应、
  且大空白带的数量 = 徽标数，就是截图时漏掉了徽标（裁切/滚动重叠所致），不是缺页。
  本次实测大空白带落在 2551–2957 / 5669–5982 / 9896–10323 / 12978–13353 / 14356–15307，
  与徽标 1/6、2/6、4/6、6/6 位置吻合，第 3、5 页徽标只是没截到。
  **只有「题号跳号」（如单选 13 直接跳到 17）才是真缺题的硬证据。**
- **拼接缝隙本身的空白带不丢内容**，别把它误判成缺页；只有页码不连续才代表缺页。
- 同理要检查**末尾**：截图常常只截到「参考答案及解析」标题就断了，答案区整段没有。

**缺页/缺答案时必须先问用户一次**，别自作主张补题：给出「补全＋配齐解析／不补题留空／
先只排版」三个选项。补题是编辑决策，不是技术细节。

## 换源：找回同一份试卷的公开原文

用试卷**标题**在公开文档站检索（常有同版）。找到后先**逐字比对**确认是同一份卷子：
标题、满分、时长、第 1—4 题是否一致 —— 标题在多个站点会被改写，句子不会。

### 取原文

**只用各站点自己提供的公开预览能力**（页面预览图、试读片段、公开文字层）。

- ⚠️ **不要尝试绕过站点的访问控制**：不用伪造搜索引擎爬虫 UA、不去拼装需要
  `token` 的预览接口、不按文件名规律枚举下载。这类做法涉及目标站的服务条款，
  且结果不可靠（枚举出来的"页"多半是错误页或水印页）。
- 站点只放出前几页时，**就只用这几页**：够确认版本、够比对标题与首题即可，
  剩余部分按「缺页/缺答案」流程先问用户。
- **确需完整原件时，走合法渠道取得**（购买、向版权方申请授权、使用用户自己持有的副本）。
  这是合规要求，也是唯一能保证文本准确的做法。

### 最省事的找源方式：拿题干里一句独特的句子去 WebSearch

**比按标题搜准得多** —— 标题会被转载站改写，句子不会。

本次实测：取题干里一句带专有名词的英文原句（连同若干关键词）一起搜，
一次就命中原始文档，并连带确认了整卷出处。同类试卷（行业英语适岗考试、
职业资格题库等）都可以用这招定位。

> 命中转载页后，**别把转载页的表格截图当原文**；能拿到原件就下原件，
> 拿不到就用「公开预览 + 用户持有副本」交叉比对，并在交付说明里写清哪些段落是推断补全。

### 公开文字层的已知偏差

不少文档站的「文字层」其实是 OCR 产物，**自带 OCR 错**（实测见过
`come iose`＝come loose、`How heading`＝How is the heading 这类）。
所以文字层只能用来**补齐缺题、缺选项、缺句子**，不能当逐字原文 ——
**必须与截图或其他副本交叉比对**再定稿。

### OCR

用 `scripts/vision_ocr.py`（macOS Vision，中文识别质量远好于通用 OCR）：

```bash
python scripts/vision_ocr.py page1.jpg page2.jpg        # 整页 OCR，按纵坐标排序输出
python scripts/vision_ocr.py page.jpg 0.44 0.46         # 只 OCR 某个纵向区间的行
```

- 【答案】等彩色标注可用**颜色通道单独提取**后 OCR，避免把答案字母读错：
  把红色像素置黑、其余置白，再整页 OCR，答案字母几乎不会错。
- 识别后用**领域知识**修正常见错字（例：「答業/答紫/答策」→「答案」）。

### 内容校订原则

- 只补"缺失/不完整"的题干与选项（源卷常有截断、缺项）。
- **原卷答案一律保留**（这是"还原"而非"重做"）。若发现原卷答案与现行教材/法规明显冲突，
  **不要静默改答案**，在交付说明里单列"待主编确认"清单。
- 不要把校订痕迹写进试卷正文（会显得像 AI 生成）。
- **先核分段分值合计**：回忆版的各大题分值经常加不出官方满分（实测一套卷
  单选30＋多选20＋判断10＋简答20＋案例15＋论述15＝110，而公告写「满分100」）。
  以公告的满分为准，**只改一处、改最小的那处**（例如把多选从「每题2分」改成「每题1分」），
  并让 `check.py` 断言合计等于官方满分；不要为了凑数去动题干本身。
- 主观题的评分构成（客观题多少分、主观题多少分）尽量保持与源卷一致，
  这样"只改一处"的改动最不容易被察觉。

## 语文卷（高考结构）还原要点

回忆版语文卷的缺口永远是这几处：语言文字运用题原文、小说/散文原文、文言文原文、诗歌原文、作文材料。
原文找不回来时的做法：

1. **材料标注**：正文写「（据考生回忆整理，有删改）」，**不要伪造作者署名**；
   整卷卷首另加一句"本卷据某年某月某日笔试考生回忆整理还原，个别材料原文因回忆限制未能逐字复原"。
2. **用主观题的答案要点反推材料**：回忆版里那串"考点①②③…"往往就是某道主观题的答案要点。
   把它当成"材料里必须出现"的特征清单（如"把听觉的唢呐声转化为色彩变化""以狂风渲染肃穆"），
   据此写材料，再据此出题——题与文才能自洽，解析也才站得住。
3. **题干里禁用"加点字／加点成语／加点词语"**：正文没有着重号标记时这句话是空的。
   要么改题干（"下列各组词语中，注音完全正确的一项""下列各句中，成语使用正确的一项"），
   要么给目标字加着重号 `text-emphasis: filled dot; text-emphasis-position: under;`（Edge 支持）。
4. **断句题必须让原文真的"断不了"**：把待断句片段在原文中**去掉标点**再加波浪线，
   否则读者对着带标点的原文一眼看穿。CSS：`text-decoration: underline; text-decoration-style: wavy;`。
   同一篇里**翻译句用横线**（`border-bottom`，与波浪线区分得开）——这是高考卷的标准标记法。
5. **排序题别用 ①②③④⑤ 的自然序**：正文按乱序给标号，正确顺序（如 ②⑤①④③）作答案；
   干扰项要踩真实逻辑坑（"而是"开头无法领起全段、"这盏灯"指代落空）。
6. **回忆版已给出的答案（如"第1题A、第2题D"）是硬约束**：先定死这几题，再给自拟题分配字母，
   最后 `check.py` 断言这几题与回忆版一致。

### 语文卷的天然留白：用"作文答题格"收尾

按「卷面从简」排（卷首通排、正文从第一页开始）后，语文卷最后仍会空出半页左右——
因为「五、写作」只有材料＋要求，约 50mm。补一块**作文答题格**正好收尾：

- `display:grid; grid-template-columns:repeat(25,1fr);` 每格 7.6mm 高、只给 `border-right/bottom`，
  容器给外框；20 行＝500 格，约占 152mm。
- 行数**按实测剩余高度定**，别写死：先出一版、跑 `measure.py` 看末页正文页剩多少，再调 `WGRID_ROWS`。
- 格纸必须紧跟写作材料**同页**，别让它单独占一页（那就白扔一页）。
- **主观题作答区在从简版式下不要加**：它会把正文挤到第二页，违背"第一页就得看见题"。
  实测珠海语文卷加 130mm 作答区后正文无法从第一页开始；删掉后 p1 直接容纳了第 1—4 题。

## 排版与导出

1. 写一份 A4 HTML：`@page { size: A4; margin: 16mm 15mm 14mm 15mm; }`
   字体：正文 `"Songti SC","STSong",serif`；标题 `"Heiti SC","STHeiti",sans-serif`。
2. 常用版式元素（**新版一律从简，见上文「卷面从简」**；下面留作需要重卷首时参考）：
   - **密封线**（默认**不用**）：左侧竖排「姓名/准考证号/考场号/座位号」+ 虚线 + 竖排「密封线内不要答题」。
     实现要点：容器 `display:flex`；字段区 `writing-mode:vertical-rl; text-orientation:upright;
     display:flex; flex-direction:column-reverse;`（这样多列按左→右排列）；虚线用独立 `width:0;
     border-right:1.6px dashed #444; align-self:stretch;` 的空 div。
     它靠 `align-self:stretch` 撑满容器，**容器必须正好是一页**（配 `page-break-after:always`）；
     卷首改成通排后会跨页撕裂，这是去掉它的主要原因。
   - **分值标注**：大题标题写「共X题，每题Y分，共Z分」即可，**不再单列分值构成表**。
   - **题量分布**：若确实要放，用「题型 × 考查模块与题号 × 题量」**三列合并行**（模块之间用「；」连写），
     **不要**每个模块占一行——模块一多（12 个以上）卷首必然溢到第二页。默认**整块不放**。
   - **答题区**：`display:grid; grid-template-columns:repeat(10,1fr);` 每格「题号 + 作答框」，
     格高 8.6mm（10 列 × 5 行＝50 格约 48mm）。题量更多时按 50 格/页估算，与卷首同页。
   - **答案解析**：`page-break-before:always`，与正文分页。
   - **考情信息表**（卷首）：字段固定为 考试名称 / 考试时间 / 考试形式 / 笔试内容 / 题型题量 /
     试卷满分 / 笔试考点 / 后续安排（成绩公布、面试形式、总成绩算法）。全部取自官方公告原文。
3. 选项排版用 `display:flex; flex-wrap:wrap; column-gap:16pt;`，短选项自动并排、长选项自动独占一行。

### 英语学科卷（阅读／七选五／完形／语法填空／读后续写）专项

- **字体栈**：`"Times New Roman", "Songti SC", "STSong", serif` —— 英文走 Times，中文自动回退宋体。
- **材料分段**：按 `\n\n` 切段、`text-indent: 2em`；段内短行（长度 < 50 且不以句号结尾）判为小标题加粗；
  需要**居中**的大标题用 `###` 前缀单独标记。只靠「长度阈值」判断会把应用文的标题行
  （如「Reading Programme 2026 — Volunteers Needed」）漏判成正文，标题就不加粗了。
- **完形填空的选项必须每题一行**：`.cloze-q { display:flex; align-items:baseline; }` + 选项容器 `flex:1 1 auto`。
  只给 `.opts` 写 `display:flex` 的话，题号与选项会被拆成两行，15 题白占两页。
- **空号渲染**：`re.sub(r"__(\d+)__", r'<span class="bl">___\1___</span>', text)`，
  必须在 `esc()` **之后**执行，否则插入的尖括号会被转义成文本。
- **七选五选项**用两列 `width:44%` 的框（`A.`~`G.`），比单列省一半纵向空间。
- **读后续写**：材料常达 300 词，整块 `page-break-before: always` 另起页最干净；
  每段段首句后给 6 行作答横线（`border-bottom: .5pt solid #b9bec6; height: 7.6mm`）。
- **题号从 1 开始**（不是 21）：教招学科卷无听力，阅读即第 1 题；46 题正好等于
  「阅读15＋七选五5＋完形15＋语法填空10＋续写1」，与考生回忆的题量天然吻合。
- **页码**：Chromium 系不支持 `@page` 的 `@bottom-center` 内容。用 pymupdf 在导出后逐页盖章：
  `page.insert_text((w/2 - get_text_length(t, "helv", 9)/2, h - 22), "- %d -", fontname="helv")`
  —— 内置 helv 字体渲染纯数字最稳，别用中文。
4. 导出 PDF（无头 Edge，无需装依赖）：
   ```bash
   "/Applications/Microsoft Edge.app/Contents/MacOS/Microsoft Edge" --headless --disable-gpu --no-sandbox \
     --no-pdf-header-footer --print-to-pdf="out.pdf" "file:///abs/path/paper.html"
   ```
   （路径含空格要 URL 编码。）
5. **务必回读校验**：用 pymupdf 把每页渲染成 PNG 逐页看，
   重点查：分页是否正确、有没有内容被截断、答案是否与正文分页。

### 行业英语卷（航海英语／船员适任英语）专项（2026-09-21 中远英语卷实测）

这类卷（中远/中远海运/海事局船员适任）结构与教招英语卷完全不同，**别套高考那套**：
`Section A 单项选择(1%×20) + Section B 短语互译(2%×20) + Section C 英译汉(4%×5) + Section D 汉译英(4%×5)`，
满分 100、考试时间 60 分钟（单选 20 分钟＋英汉互译 40 分钟）。

- **选项只有 A/B/C 三项**，不是四项。`LETTERS = "ABC"`，check 里断言 `len(opts) == 3`。
- **短语互译用两列网格最省地方**（20 条＝10 行，约 70mm）：
  ```css
  .phgrid { display:grid; grid-template-columns:1fr 1fr; column-gap:11mm; row-gap:3.4mm; }
  .ph { display:flex; align-items:baseline; }
  .ph .pfill { flex:1 1 auto; border-bottom:.5pt solid #b9bec6; height:5.4mm; margin-left:2mm; }
  ```
- **句子翻译（C/D）的作答横线数要靠末页余量反推**：本次 `ANS_LINES=2` 时正文末页剩 117mm
  （超阈值一大截），改 `3` 后降到 47.6mm，8 页版式收敛。做法：出一版→`measure.py`→只调
  `ANS_LINES` 再出，通常两轮就够。
- **题干里英文短语与空线之间要有空格**，否则 `"______" "Two degrees, on starboard."`
  这类纯对话题会挤成 `"______""Two degrees..."`，看着像漏了标点。
- **还原卷不要打匀答案分布**。「打匀」只适用于自拟题（见上文「用户明确要求补足到 N 分」）。
  原卷答案位置是历史事实，本次 20 题实测 A5/B5/C10，照原样出，别去「优化」。

### 学科知识卷（生物／化学／物理等）专项

教招「学科专业知识」卷（如高中生物）与公基卷差别很大：题量少（16 选择＋5 大题）、满屏图表、
大题要配手绘示意图，照抄公基卷的 build.py 会立刻卡住。

- **题源：这类卷子常整卷照搬当年高考真题。** 拿到回忆稿先挑几句**题干关键句**去公开题库检索，
  往往一搜即中，一次就能锁定原题、选项与答案。实测某地市教招生物卷：
  第 5 题＝某年某省选考第 12 题（逐字一致）、第 9 题＝另一年某省卷、第 4 题＝该卷第 18 题改编。
- **核对原题时只用各站点公开提供的内容**（公开预览页、公开题库页），
  **不要尝试绕过站点的访问控制**（伪造爬虫 UA、拼装带 `token` 的接口、按文件名枚举下载）——
  涉及服务条款，且拿到的往往是水印页或错误页。**确需完整原件走合法渠道取得**。
- **回忆稿的设问词可能是错的——必须先回原题核对。** 实测某省卷原题是「下列说法**错误**的是」＋**多选**（答案两项），
  回忆稿记成「正确的是」＋单选，且把其中一项从「衰退型」记成「增长型」；照抄会出现一题三正确。
  **以原题为准做最小修正**，并在**交付说明里告知用户**，
  不把校订痕迹写进试卷正文。
- **生物卷常用 SVG（手写，不引库）**：系谱图（○女/□男，符号下方标表型，世代标 Ⅰ/Ⅱ/Ⅲ）、
  酶催化示意图（两条折线＋虚线表示氢键＋切割位点）、种群增长率—密度曲线（**x 轴本身画成增长率 0 线**，
  这样能画出负增长区）、培养皿划线生长图（浅灰粗划线＋深色斑块表示生长旺盛）、
  质粒元件图（矩形盒子＋启动子箭头＋图注）、双折线对照图（图 1／图 2 并排）。
- **图幅必须逐图设 `max-width`。** `svg.fig` 只写一个 `max-width` 时，正方形 viewBox 的图（培养皿）
  会撑到与宽度同高（74%×180mm → 133mm，占半页）。给每张图加 `.fig-xxx` 类分别限宽：
  系谱 43—46%、曲线 51—58%、培养皿 34—38%、质粒 86—90%、双折线 78—84%。
- **不要靠「全局压行距＋缩图」来减页。** 实测把 line-height 1.6→1.54、各 margin 收 0.4mm、图幅缩 10%，
  正文页数一页没少，反而把空白全推到末页（某页从 84mm 变 153mm）。正文页数由「内容总高 ÷ 页高」决定，
  压缩只改变空白的分布位置，不改变页数。
- **正文末页的空白是分节断点，不是排版失误。** 「参考答案及解析」强制分页，正文最后一页必然留白。
  判断方法：`free_mm` 超阈值的那页**如果是某一节的最后一页，可以接受**；只在中段出现才算没排好。
- **`fillcheck.py`（量空白，比目检快）**：用 pymupdf 取每页 `get_text("blocks")` 的最大 bottom，
  **排除页脚页码**（`b[3] < h-40`），再换算成 mm；>60mm 的页打标记人工判读。

## 已知坑

- **答案速查表（`table.quick`）必须加 `table-layout: fixed`**。若只给题号列写 `td.k{width:50%}`，
  一行 20 个单元格会互相抢宽度，渲染出来列宽忽宽忽窄、很难看。改成 `table-layout:fixed` 后
  各列自动均分（10 组=每组 10%，5 组=每组 20%）。
- **答题卡单元格别用 `'...%d...'` 当字面模板**：`'<div>%d</div>'` 不接 `% i` 就会把 `%d` 原样打进 PDF。
  生成后务必回读一页确认题号是数字。
- **图形推理的两个观感要点**（不做到会显得不像真题）：
  ① 题干末尾要有**虚线「?」占位框**（`.qm{width:70px;height:70px;border:1.6px dashed #8a8f97}`），
     否则 4 个题干图后面直接跟 A/B/C/D，读者会以为标号属于题干图；
  ② **选项的 A/B/C/D 标号放在图形下方**（`.optfig{flex-direction:column}`，svg 在前、`b` 在后）。
     标号放图形上方时，题干图与选项图之间夹着一行标号，极易误读成"题干图 = ABCD"。
- **主观题整块 `page-break-before: always` 要按内容长度决定，不能无脑加**：
  材料题很长时，顺排会把第二题挤到下一页、那页只剩两三行；此时让「四、主观题」另起页是对的。
  但主观题短（如只有简答＋案例＋论述的题干）而前面恰好空着半页时，强制分页反而白扔一页——
  实测同一套模板去掉这条规则后 10 页→9 页。判断方法：先按「主观题不另起页」出一版，
  目检分页；只在真的出现"挤到下一页且上一页大面积留白"时才加回来。
  另给 `.material` 加 `page-break-inside: avoid` 防止材料被拦腰截断。
- **判断题（无选项）要单独处理**：`Q(opts=[])` 时渲染期在题干末尾补「（　　）」，
  且 `check.py` 要断言判断题不得带选项；否则要么渲染成空 `.opts` 要么漏掉答题括号。
- **主观题参考答案别用 `<ol>`**：答案要点本身已带「（一）（二）」，
  再套有序列表会渲染成「1. （一）…」重号。用 `list-style:none` 的 `<ul>`。
  要点标题（`.pt`）还要给 `margin-right: 1.2mm`，否则标题与正文黏成一行读不出层次。
- **卷首不要单独占一页**（2026-09-20 起从简）。老做法是卷首 `display:flex` 装密封线、
  再 `page-break-after:always` 独占一页，结果是「封面 1 页 + 须知/答题卡 1 页」两张纸
  才见到第一道题，用户明确要求改掉。**新做法见「卷面从简」**：去掉密封线、考情压到 5 行、
  须知与答题卡前置到第一页，全部通排。若将来真需要重卷首，记住密封线的 `align-self:stretch`
  必须配「容器正好一页」，否则跨页撕裂。
- **图形推理 SVG**：题干图与选项图**都不内置文字标签**，题干文字、A/B/C/D 由外层 HTML 提供，
  否则会出现重复标签。平行四边形别误用 `polygon` 画成正方形（对角坐标必须真的错开）。
- **图推题干与选项的顺序陷阱**：把图推整块插进 `QS` 列表时，切片下标算错会让图推落到别的模块区间
  （实测把图推插成了第 51—55 题，与「（二）数学运算（第55—60题）」标题打架）。插完立刻用
  「题号 × 模块」对照表核一遍：题干里的模块区间文字与实际题号必须完全吻合。
- **图形推理的稳妥题型（好画又不易出错）**：①边数/直线数递增（正多边形 `polygon` 顶点算角度即可）
  ②封闭区域数递增（正方形内加 n 条等距竖线，n+1 个区域）③黑点在方框四角顺时针旋转
  ④对称轴条数递增（等腰三角形1／长方形2／等边三角形3／正方形4 → 正五边形5）⑤一笔画
  （奇点数为 0 或 2；"日"字 2 奇点可一笔画，"田"字 4 奇点需两笔，正方形加两条对角线 4 奇点）。
  别用「数三角形个数」这类题，重复计数极易自摆乌龙。
- **资料分析自绘矢量图表**：分组柱状图与饼图都用原生 SVG 手写即可，比引库更可控。踩过的两个坑：
  ①**柱状图的图例与最高的那根柱的数据标签会重叠**——把顶部留白 `T` 从 22 提到 44 才够；
  ②**饼图内置标题会和顶部扇形的引导标签撞车**，且左侧标签 `text-anchor="end"` 容易被 viewBox 裁掉——
  去掉内置标题（改由下方 `图X　……` 图题承担），并把圆心右移、viewBox 加宽。
- **资料分析的材料数据尽量用真实可核的**：优先取官方公告/统计公报里的原始数字（如各区县岗位数与报名数、
  三次产业增加值），这样解析能逐项验证，也不怕被追问出处。
- **骰子展开图 SVG（可直接抄）**：用 4×3 网格定位六个面，`_PIP_LAYOUT` 存 1~6 点的九宫格索引
  （1→中；2→左上+右下；3→左上+中+右下；4→四角；5→四角+中；6→四角+左右中）。
  展开图用 T 型网 `1 / 2 3 5 4 / 6`，相对面为 (1,6)(2,5)(3,4)。
  **相对面判定**：同一行里相隔一个格的两面互为相对面；Z 字型两端也互为相对面。
  选项画单个点数方格即可（不必画立体骰子，立体图要处理手性，极易出错）。
- **章节标题孤行**：`h3.part` / `h4.sub` / `.part-note` 必须加 `page-break-after: avoid`。
  否则「三、判断题（共10题…）」这类标题会留在上一页页底、题目全翻到下一页，观感很差。
- **同文件多个 Edit 必须串行提交**。并行改同一个 `content.py` 会静默丢更新（本次又踩一次：
  `MODULE_TABLE` 的压缩改动被同批的另一个 Edit 覆盖，卷首照旧溢页）。改完 `grep` 复核再重跑。
- **长脚本别接 `| head`**：`render.py | head -3` 会让 head 提前关管道触发 SIGPIPE，
  渲染脚本中途被杀、只写出前两张图。要么不加管道，要么重定向到日志再 tail。
- **vqa 块整体 `page-break-inside:avoid`** 会让上一页底部空出 30–40mm，这是正常现象，不必强拆；
  强拆反而会把选项和题干分到两页，观感更差。
- 若卷首用了 `overflow:hidden` 又给了固定高度，超出部分会被**静默裁掉**，一定要回读校验。
- macOS 默认无 `wkhtmltopdf`；`weasyprint` 只有系统 Python 有。**优先用无头 Edge**。
- 不要用 `sed -i` 改含方括号的脚本内容（易失败），直接用文件写入工具。

### 2026-09-20 珠海物理卷（图形多、大题长）新增的六条

1. **大题头＋长题干＋大图是一个「不可拆的整体」，会把上一页撑出 80—100mm 空白。**
   默认 `.subj { page-break-inside: avoid; }` 会让整道计算题（含图）跳到下一页；
   但**不能**因此把题干和插图拆开——学生会翻页找图，这是硬伤。正确做法是分两层：
   ```css
   .subj-auto { page-break-inside: auto; break-inside: auto; }   /* 大题允许跨页 */
   .calc-head { page-break-inside: avoid; break-inside: avoid; } /* 只锁题干+图 */
   ```
   渲染时 `<div class="subj subj-auto"><div class="calc-head">题号+题干+图</div><div class="qlist">小问…</div></div>`，
   这样小问可以流到下一页，题干与图始终黏在一起。
   实验题同理（`subj-auto`），且**每个小问要包成独立的 `.vqa`**，粒度小才好塞。
2. **两幅并排插图在 flex 容器里分页必出异常**（被拆到两页、或留白忽大忽小）。
   不要靠调 `.figrow` 的 flex 参数去救——**把两幅图合并成一张 SVG**最稳：
   ```python
   def _svg_inner(html):                       # 取出 <svg>…</svg> 的内部内容
       m = re.search(r"<svg[^>]*>(.*?)</svg>", html, re.S)
       return m.group(1) if m else ""
   FIG_AB = '<div class="figbox"><svg viewBox="0 0 700 252" width="640" height="230">' \
            '<g transform="scale(0.98)">%(A)s</g>' \
            '<g transform="translate(345,0) scale(0.92)">%(B)s</g>' \
            '<text x="152" y="247" font-size="11" fill="%(S)s" text-anchor="middle">图甲</text>' \
            '<text x="522" y="247" font-size="11" fill="%(S)s" text-anchor="middle">图乙</text>' \
            '</svg><div class="figcap"></div></div>' % {"A": _svg_inner(FIG_A), "B": _svg_inner(FIG_B), "S": STK}
   ```
   图题也写进 SVG 内部（用 `<text>`），一张图就是**一个不可拆的块**，分页立刻正常。
   ⚠️ **并排合并会把画幅压扁**：两幅原本各占半宽，合并后每幅只剩 ~48% 宽，字号要预先放大
   （本次把子图内文字从 10.5px 提到 11—12px 才在纸上清晰）。
3. **SVG 模板的 `%` 格式化必须统一用命名占位。** 混用会直接报
   `TypeError: format requires a mapping`——写 `"""…""" % (_ticks(),) % {"S": STK}` 或
   `% ({"S": STK} and _ticks()) % {...}` 都是错的。**模板里一律写 `%(TICKS)s`／`%(S)s`，
   一次性传一个 dict**：`% {"S": STK, "A": AUX, "TICKS": _ruler_ticks()}`。
4. **空的 `<div class="figcap"></div>` 会白占 `min-height: 4mm`**（多张图叠起来就是十几毫米）。
   加一条 `.figcap:empty { display: none; }` 即可——不需要图题的图就别塞占位 div。
5. **`free_mm > 60mm` 的自检规则有两个合法例外**，判读时别误报：
   - **某一节的最后一页**（如正文末页、某大题的末页）；
   - **大题起始页**：若某页尾部紧跟的「大题标题＋题注＋首题题干＋首题插图」整块高度 > 剩余空间，
     该页就会留白。本次物理卷 p4 剩 86mm，而「四、计算题」头＋第13题题干＋合并图 ≈115mm，
     要填满只能把题干与插图拆到两页——**宁可留白，不可拆图**。
     判断方法：把「剩余 mm」与「下一块的整块高度」比一下；差距 < 30% 才值得回去微调
     （调 `h2.part-h2` 的 padding/margin、把 `part-note` 并进标题行），差距过大就是数学上无解。
6. **`figs.py` 独立成模块（图形与内容分离）值得沿用。** `content.py` 里只写 `figs=["FIG_XXX"]`，
   渲染期 `F.FIGS.get(key, "")`；图形全部内联原生 SVG、不引任何外部库，
   这样「改图不动数据、改数据不动图」，也方便把同一张图在题干与解析里复用。
   刻度尺／螺旋测微器这类规则刻度用生成函数（`_ruler_ticks()` / `_micro_ticks()`，1 mm＝15 px）画，
   比手写几十条 `<line>` 可靠得多。

### 红线：交付件里不许出现「笔记式表述」（2026-09-23 物理卷返工实测）

**这是回忆稿整理最容易踩、也最伤专业感的一条。** 用户原话：
「不需要出现这些不正规的表述，全部合理的推导还原成题目即可」。

回忆稿常带一批「只记得考点、没记住题干」的内容，整理时很容易顺手写成
「考点名：……／【参考解答】……」——这是**复习笔记**的口吻，印在试卷上就是硬伤。
**凡出现「考点」「参考解答」「不计入卷面分值」「补充回忆」这类字样的，一律改写成标准题目**
（题干＋四个选项＋答案＋解析），并**并入它所属的正常大题**，不要在卷面上单独辟一节
「补充回忆考点」——那等于把「这不是真题」写在脸上。

改写的具体做法（本次 5 项）：

1. **按考点拟一道能考出该知识点的单选题**，四个选项都要像真选项（错误项用典型误区，
   如「转动惯量单位写成 kg·m/s²」「不确定性关系漏掉 1/(4π) 因子」），别凑数。
2. **并入正确的分部，全卷重排。** 本次把 5 道并进「学科单选」，该节由 15 题×4 分
   改为 20 题×3 分（**小计仍是 60 分，总分结构不动**）；原多选由 20—22 顺延为 25—27。
   要点：**改题量时优先调「每题分值」保住各部分小计，这样只需动 PARTS 和答题卡**。
3. **同步三处**：① `PARTS` 的题号区间与分值；② 答题卡格数（1—27）；
   ③ `check.py` 的 `single`/`multi` 区间、分值式、并加一条
   `assert not [q for q in qs if q.get("point")]`（防止笔记式条目复活）。
4. **答题卡里主观题不设填涂框**：本次第 4 题是材料分析题，给它的 `.bx` 加
   `style="visibility:hidden"`（保留格高、去掉圆圈），比留个空圈专业。
5. **加题后分页会溢出，压缩解析区比压缩正文更有效。** 加 5 题后变 10 页、末页只剩 64mm
   （203mm 空白），观感很差。把解析区 `.expitem` 由 `9.6pt/1.5/1.6mm` 压到
   **`9.4pt/1.42/1.2mm`**，解析由 4 页收到 3 页 → 回到 9 页、末页余量 2.0mm。
   **判据：若某节总高只比整页数多一点点（如 3.24 页），压缩 5%—8% 就能省下整页；
   这与「孤行只调段距」是两回事——要省页必须动行高＋字号。**
